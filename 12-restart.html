Restart policiesسیاست‌های راه‌اندازی مجدد

Programs crash, and computers reboot. By default, a container that stops stays stopped. A restart policy tells Docker to bring it back by itself.برنامه‌ها crash می‌کنند و کامپیوترها ری‌استارت می‌شوند. به‌طور پیش‌فرض، کانتینری که متوقف شود متوقف می‌ماند. یک سیاست راه‌اندازی مجدد (restart policy) به Docker می‌گوید خودش آن را برگرداند.

Press → or Space to startبرای شروع → یا Space را بزنید

Step 1قدم ۱

A program that crashesبرنامه‌ای که crash می‌کند

Let's fake a crashing app. This container prints started, waits 3 seconds, then quits with an error (code 1):بیایید یک برنامه‌ی crash‌کننده بسازیم. این کانتینر started را چاپ می‌کند، ۳ ثانیه صبر می‌کند و بعد با خطا (کد 1) تمام می‌شود:

bash
docker run -d --name crashy alpine sh -c "echo started; sleep 3; exit 1"

sh -c "…" runs several commands, separated by ;.sh -c "…" چند دستور را که با ; جدا شده‌اند اجرا می‌کند.

Step 1 · Checkقدم ۱ · بررسی

It crashed, and it stays crashedcrash کرد و crash‌شده می‌ماند

bash
docker ps -a
NAMES     STATUS                     # other columns left out
crashy    Exited (1) 3 seconds ago
docker logs crashy
started
docker rm crashy
crashy

It crashed, and it stays crashed. Nobody starts it again.crash کرد و crash‌شده می‌ماند. کسی دوباره راهش نمی‌اندازد.

Its log shows it started only once.لاگش نشان می‌دهد فقط یک بار شروع شده.

Step 2قدم ۲

Add --restartاضافه کردن ‎--restart

bash
docker run -d --name crashy --restart unless-stopped alpine sh -c "echo started; sleep 3; exit 1"
6b2e9f4a1d7c3e0b8a5f2d9c6e1b4a7f0d3c8e5b2a9f6d1c4e7b0a3d8f5c2e9b
✅

Every time it crashed, Docker started it again. Each restart waits a bit longer than the previous one, so a broken app doesn't restart thousands of times.هر بار که crash کرد، Docker دوباره راهش انداخت. هر راه‌اندازی مجدد کمی بیشتر از قبلی صبر می‌کند، تا یک برنامه‌ی خراب هزاران بار راه نیفتد.

bash
docker logs crashy
started
started
started
started
started
docker ps
NAMES     STATUS          # other columns left out
crashy    Up 3 seconds
Step 3قدم ۳

You stop it: does it come back?خودتان متوقفش کنید: برمی‌گردد؟

bash
docker stop crashy
crashy
docker ps -a
NAMES     STATUS                     # other columns left out
crashy    Exited (1) 8 seconds ago
docker rm crashy
crashy
unless-stopped

It stays stopped. That's the unless-stopped part: Docker restarts it after crashes, but respects your docker stop.متوقف می‌ماند. این همان بخش unless-stopped است: Docker بعد از crash آن را دوباره راه می‌اندازد، ولی به docker stop شما احترام می‌گذارد.

We can't reboot your PC in a lesson, but after a reboot Docker starts again and brings back every container whose policy says so.در یک درس نمی‌توانیم کامپیوتر شما را ری‌استارت کنیم، ولی بعد از ری‌استارت، Docker دوباره اجرا می‌شود و هر کانتینری را که سیاستش بگوید برمی‌گرداند.

Step 4 · The usual choiceقدم ۴ · انتخاب معمول

For things that should always runبرای چیزهایی که باید همیشه اجرا باشند

🔑

For anything that should always be running, like a database or a web server, use --restart unless-stopped. For example, the database from Lesson 11:برای هر چیزی که باید همیشه در حال اجرا باشد، مثل یک دیتابیس یا وب‌سرور، از --restart unless-stopped استفاده کنید. مثلاً دیتابیس درس ۱۱:

just look, don't runفقط نگاه کنید، اجرا نکنید
docker run -d --name db --restart unless-stopped --env-file db.env postgres:alpine
