Install Dockerنصب Docker

Set up your machine once: check your system, install the prerequisites, install Docker Engine from Docker's official repository, and test it.سیستم خود را یک بار آماده کنید: سیستم را بررسی می‌کنید، پیش‌نیازها را نصب می‌کنید، Docker Engine را از مخزن رسمی Docker نصب می‌کنید و آن را تست می‌کنید.

Press → or Space to startبرای شروع → یا Space را بزنید

Before we startقبل از شروع

“Docker” is a few programs«Docker» یعنی چند برنامه

They work together. One apt install gives you all of them:این برنامه‌ها با هم کار می‌کنند. یک apt install همه‌ی آن‌ها را نصب می‌کند:

docker-ce

The Docker daemon (dockerd): a background service that builds images and runs containersسرویس Docker (dockerd): برنامه‌ای که در پس‌زمینه اجرا می‌شود و ایمیج می‌سازد و کانتینر اجرا می‌کند

docker-ce-cli

The docker command you type. It only sends requests to the daemonدستور docker که شما تایپ می‌کنید. فقط درخواست‌ها را به سرویس می‌فرستد

containerd.io

The low-level runtime that actually starts and stops containersruntime سطح پایین که در واقع کانتینرها را روشن و خاموش می‌کند

buildx-plugin

The modern image builder behind docker buildسازنده‌ی مدرن ایمیج که پشت docker build کار می‌کند

compose-plugin

docker compose: run several containers together from one YAML filedocker compose: اجرای چند کانتینر با هم از روی یک فایل YAML

⚠ You need sudo rights, an internet connection, a 64-bit CPU, and at least 2 GB of RAM and 10 GB of free disk.⚠ به دسترسی sudo، اینترنت، پردازنده‌ی ۶۴ بیتی، و حداقل ۲ گیگابایت RAM و ۱۰ گیگابایت فضای خالی دیسک نیاز دارید.

Step 2.1قدم ۲.۱

Remove old versionsحذف نسخه‌های قدیمی

Ubuntu ships its own unofficial Docker packages. They conflict with the official ones, so remove them if present.Ubuntu بسته‌های غیررسمی Docker خودش را دارد. این‌ها با بسته‌های رسمی تداخل دارند، پس اگر نصب هستند حذفشان کنید.

bash
sudo apt remove $(dpkg --get-selections docker.io docker-compose docker-compose-v2 docker-doc podman-docker containerd runc | cut -f1)
# safe to run even if none are installed
sudo snap remove docker
# only if you installed Docker as a snap
❓ $( … )

It runs first and prints only the names from that list that are actually installed. Those names are passed to apt remove, so apt never complains about a package you don't have.این بخش اول اجرا می‌شود و فقط نام بسته‌هایی از آن فهرست را که واقعاً نصب هستند چاپ می‌کند. همین نام‌ها به apt remove داده می‌شوند، پس apt درباره‌ی بسته‌ای که ندارید خطا نمی‌دهد.

(The picture is an example: which ones are installed depends on your PC.)(تصویر فقط یک مثال است: اینکه کدام‌ها نصب باشند به کامپیوتر شما بستگی دارد.)

Step 2.2قدم ۲.۲

Install the prerequisitesنصب پیش‌نیازها

bash
sudo apt update
# refresh the list of available packages
sudo apt install -y ca-certificates curl
...
curl --version
curl 8.5.0 (x86_64-pc-linux-gnu) ...       # ✅ prints a version

ca-certificates lets your system trust HTTPS websites, and curl downloads files. We need both to fetch Docker's signing key.ca-certificates باعث می‌شود سیستم به سایت‌های HTTPS اعتماد کند و curl فایل دانلود می‌کند. برای گرفتن کلید امضای Docker به هر دو نیاز داریم.

Step 3.1 · Docker's apt repositoryقدم ۳.۱ · مخزن apt داکر

Docker's signing keyکلید امضای Docker

We tell apt where to download Docker from, and give it Docker's key so it can check the packages are genuine.به apt می‌گوییم Docker را از کجا دانلود کند و کلید Docker را به آن می‌دهیم تا بتواند اصل بودن بسته‌ها را بررسی کند.

bash
sudo install -m 0755 -d /etc/apt/keyrings
# create the folder for keys
sudo curl -fsSL https://download.docker.com/linux/ubuntu/gpg -o /etc/apt/keyrings/docker.asc
# download Docker's key into it
sudo chmod a+r /etc/apt/keyrings/docker.asc
# let everyone read the key
Step 3.2قدم ۳.۲

Add the repositoryاضافه کردن مخزن

bash · paste the whole block at oncebash · کل بلوک را یک‌جا paste کنید
$ sudo tee /etc/apt/sources.list.d/docker.sources <<EOF
Types: deb
URIs: https://download.docker.com/linux/ubuntu
Suites: $(. /etc/os-release && echo "${UBUNTU_CODENAME:-$VERSION_CODENAME}")
Components: stable
Signed-By: /etc/apt/keyrings/docker.asc
EOF
(pasted block)
# writes a small config file for apt
sudo apt update
Hit:1 http://archive.ubuntu.com/ubuntu noble InRelease
Get:2 https://download.docker.com/linux/ubuntu noble InRelease
...
cat /etc/apt/sources.list.d/docker.sources
Types: deb
URIs: https://download.docker.com/linux/ubuntu
Suites: noble
Components: stable
Signed-By: /etc/apt/keyrings/docker.asc
📄 docker.sources
Types: deb
URIs: …/linux/ubuntu
Suites: $( … )noble
Components: stable
Signed-By: …/docker.asc
❓ Suites: $( … )

It reads /etc/os-release and inserts your Ubuntu codename, e.g. noble for 24.04. On Linux Mint it picks the Ubuntu codename Mint is based on.فایل /etc/os-release را می‌خواند و اسم رمز نسخه‌ی Ubuntu شما را قرار می‌دهد، مثلاً noble برای 24.04. روی Linux Mint اسم رمز Ubuntuای را برمی‌دارد که Mint بر پایه‌ی آن ساخته شده.

✅

In the output of sudo apt update you should see a line containing download.docker.com with no errors.در خروجی sudo apt update باید خطی شامل download.docker.com ببینید، بدون خطا.

🔍

Check the file: a real codename, not an empty Suites: line.فایل را بررسی کنید: خط Suites: خالی نیست و یک اسم رمز واقعی دارد.

Step 4قدم ۴

Install Docker Engineنصب Docker Engine

bash
sudo apt install -y docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
...
systemctl is-active docker
active        # running now
systemctl is-enabled docker
enabled       # starts on every boot
NOT active / enabled?active / enabled نیست؟

Start and enable it:سرویس را روشن و فعال کنید:

sudo systemctl enable --now docker.service containerd.service

💡 WHICH VERSION?چه نسخه‌ای؟

sudo docker version shows two parts: Client (the CLI) and Server (the daemon). If Server is missing, the daemon isn't running.sudo docker version دو بخش نشان می‌دهد: Client (دستور CLI) و Server (سرویس). اگر بخش Server نباشد، سرویس اجرا نمی‌شود.

Step 5قدم ۵

Run Docker without sudoاجرای Docker بدون sudo

bash
sudo usermod -aG docker $USER
# add yourself to the docker group
newgrp docker
# or log out and log back in
groups
you adm sudo … docker     # "docker" should be in the list
docker run --rm hello-world
Hello from Docker!
This message shows that your installation appears to be working correctly.
newgrp

newgrp only affects the current terminal. If another terminal says permission denied, log out and log back in (or reboot).newgrp فقط روی همین ترمینال اثر دارد. اگر ترمینال دیگری خطای permission denied داد، یک بار log out و دوباره log in کنید (یا سیستم را ری‌استارت کنید).

✅

“Hello from Docker!” without sudo: Docker is installed. What actually happened is the topic of the next lessons.«Hello from Docker!» بدون sudo: Docker نصب شد. اینکه دقیقاً چه اتفاقی افتاد موضوع درس‌های بعدی است.

⚠

The docker group is as powerful as root: anyone in it can start a container that reads any file on the machine. Fine on your own laptop; on a shared server, only add trusted users.عضویت در گروه docker به اندازه‌ی root قدرت دارد: هر عضو آن می‌تواند کانتینری اجرا کند که هر فایلی روی سیستم را بخواند. روی لپ‌تاپ شخصی مشکلی نیست؛ روی سرور مشترک فقط کاربران مورد اعتماد را اضافه کنید.

Not on Ubuntu?Ubuntu ندارید؟

Install Docker Desktop (pick Apple Silicon or Intel), open it once, and wait for the whale icon to say running.Docker Desktop را نصب کنید (نسخه‌ی Apple Silicon یا Intel)، یک بار بازش کنید و صبر کنید تا آیکون نهنگ وضعیت running را نشان دهد.

If something goes wrongاگر چیزی درست کار نکرد

Troubleshootingرفع اشکال

permission denied ... docker.sock

You're not in the docker group in this terminal yet. Redo Step 5, then log out and log back in.هنوز در این ترمینال عضو گروه docker نیستید. قدم ۵ را دوباره انجام دهید و یک بار log out و دوباره log in کنید.

Cannot connect to the Docker daemon

The daemon isn't running. Run sudo systemctl start docker and check sudo journalctl -u docker for errors.سرویس اجرا نمی‌شود. sudo systemctl start docker را اجرا کنید و خطاها را با sudo journalctl -u docker ببینید.

apt update: 404 Not Found / does not have a Release file

Wrong distro or codename in docker.sources. Check it with cat; on Debian use linux/debian.توزیع یا اسم رمز در docker.sources اشتباه است. با cat بررسی کنید؛ روی Debian از linux/debian استفاده کنید.

apt update: Conflicting values set for option Signed-By

An older Docker repo file is still there. Look at ls /etc/apt/sources.list.d/ and remove the old docker.list with sudo rm.یک فایل قدیمی مخزن Docker هنوز وجود دارد. ls /etc/apt/sources.list.d/ را ببینید و فایل قدیمی docker.list را با sudo rm حذف کنید.

toomanyrequests: ... pull rate limit

Docker Hub limits anonymous downloads. Create a free account and run docker login, or wait a few hours.Docker Hub تعداد دانلود بدون حساب کاربری را محدود می‌کند. یک حساب رایگان بسازید و docker login کنید، یا چند ساعت صبر کنید.

⚠ START OVER COMPLETELYشروع کاملاً از اول

This uninstalls Docker and deletes all images, containers and volumes:این دستورها Docker را حذف می‌کنند و همه‌ی ایمیج‌ها، کانتینرها و volumeها را پاک می‌کنند:

sudo apt purge -y docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
sudo rm -rf /var/lib/docker /var/lib/containerd
