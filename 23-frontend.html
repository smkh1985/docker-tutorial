import os import requestsimport streamlit as st API_URL = os.environ["API_URL"] st.title("My shop") name = st.text_input("New product")if st.button("Add") and name:    requests.post(f"{API_URL}/products", params={"name": name}) st.subheader("Products")for product in requests.get(f"{API_URL}/products").json():    st.write("•", product)
Step 3قدم ۳

The frontend's DockerfileDockerfile مربوط به frontend

Create frontend/Dockerfile. Same pattern as the API (Lessons 19 and 22):frontend/Dockerfile را بسازید. همان الگوی API (درس‌های ۱۹ و ۲۲):

📄 ~/shop-api/frontend/Dockerfile
FROM python:3.13-slimWORKDIR /appCOPY requirements.txt .RUN pip install -r requirements.txtCOPY . .EXPOSE 8501CMD ["streamlit", "run", "app.py", "--server.address", "0.0.0.0", "--server.headless", "true"]

--server.address 0.0.0.0

Listen on all addresses of the container, like uvicorn's --host 0.0.0.0 (Lesson 22).روی همه‌ی آدرس‌های کانتینر گوش بده، مثل --host 0.0.0.0 در uvicorn (درس ۲۲).

--server.headless true

Just run the server: don't try to open a browser or ask questions inside the container.فقط سرور را اجرا کن: سعی نکن داخل کانتینر مرورگر باز کنی یا سؤال بپرسی.

EXPOSE 8501

Streamlit uses port 8501. Create frontend/.dockerignore so the build files stay out of this image (Lesson 20):Streamlit از پورت 8501 استفاده می‌کند. frontend/.dockerignore را بسازید تا فایل‌های ساخت بیرون از این ایمیج بمانند (درس ۲۰):

Open ~/shop-api/compose.yaml. Add the frontend service at the top, and remove the ports lines from api.~/shop-api/compose.yaml را باز کنید. سرویس frontend را در بالا اضافه کنید و خط‌های ports را از api حذف کنید.

api: no portsapi: بدون ports

Only the frontend needs the API, and it's inside the network. Your browser doesn't need to reach the API directly (same idea as db in Lesson 13).فقط frontend به API نیاز دارد و آن داخل شبکه است. مرورگر شما لازم نیست مستقیم به API برسد (همان ایده‌ی db در درس ۱۳).

Step 7قدم ۷

The API is privateAPI خصوصی است

Try to reach the API directly from your PC, like in Lesson 22:سعی کنید مثل درس ۲۲ مستقیماً از کامپیوترتان به API برسید:

❌ From your PC, the API is unreachable, because it has no ports. Yet the web page works, because the frontend talks to api inside the project's network.❌ از کامپیوتر شما، API در دسترس نیست، چون ports ندارد. با این حال صفحه‌ی وب کار می‌کند، چون frontend داخل شبکه‌ی پروژه با api صحبت می‌کند.

🔑

Open only what users need: here, just the frontend. The API and the database stay inside, where outsiders can't reach them. That's safer, and it's how real apps are deployed.فقط چیزی را باز کنید که کاربران لازم دارند: اینجا فقط frontend. API و دیتابیس داخل می‌مانند، جایی که غریبه‌ها به آن‌ها دسترسی ندارند. این امن‌تر است و برنامه‌های واقعی همین‌طور منتشر می‌شوند.
