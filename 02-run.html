Lesson 2 — Run a container درس ۲ — اجرای کانتینر

In Lesson 1 you learned that an image is the recipe. Now you'll run the hello-world image to make a container, see it, and delete it.

در درس ۱ یاد گرفتید که ایمیج مثل دستور پخت است. حالا ایمیج hello-world را اجرا می‌کنید تا یک کانتینر ساخته شود، آن را می‌بینید و حذفش می‌کنید.

🧠 Blurred commands are ones you've already learned. Try to remember them, then click to check.

🧠 دستورهای محو را قبلاً یاد گرفته‌اید. سعی کنید به یاد بیاورید، بعد کلیک کنید و ببینید.

Imageایمیجhello-world
docker run
Containerکانتینرruns, prints a message, exitsاجرا می‌شود، پیامی چاپ می‌کند، تمام می‌شود

1 Run itاجرا Doneانجام شد

bash
docker run hello-world
output

Hello from Docker!
This message shows that your installation appears to be working correctly.
...

docker run did two things: it created a new container from the image, and started it. The program inside printed the message and finished, so the container stopped.

docker run دو کار کرد: از روی ایمیج یک کانتینر جدید ساخت و آن را اجرا کرد. برنامه‌ی داخل آن پیام را چاپ کرد و تمام شد، پس کانتینر هم متوقف شد.

❓ The message says Docker “pulled the image from Docker Hub”. Did it download it again?❓ پیام می‌گوید Docker ایمیج را «از Docker Hub دانلود کرد». یعنی دوباره دانلودش کرد؟

No. That text is always the same. The image was already on your PC from Lesson 1, so there was no Unable to find image … locally line at the top. That line only appears when Docker really has to download.

نه. آن متن همیشه ثابت است. ایمیج از درس ۱ روی کامپیوتر شما بود، پس خط Unable to find image … locally در بالای خروجی نیامد. آن خط فقط وقتی می‌آید که Docker واقعاً مجبور به دانلود باشد.

2 See the containerدیدن کانتینر Doneانجام شد

The container stopped, but it still exists. List all containers, including stopped ones:

کانتینر متوقف شده، ولی هنوز وجود دارد. همه‌ی کانتینرها را، حتی متوقف‌شده‌ها، فهرست کنید:

bash
docker ps -a
output
CONTAINER ID   IMAGE         COMMAND    CREATED         STATUS                     NAMES
978227142bc2   hello-world   "/hello"   4 seconds ago   Exited (0) 2 seconds ago   tender_visvesvaraya
Columnستون Meaningمعنی
CONTAINER IDThe container's unique IDشناسه‌ی یکتای کانتینر
IMAGEThe image it was made fromایمیجی که کانتینر از روی آن ساخته شده
STATUSExited (0) = finished, and 0 means no error. A running container shows Up …Exited (0) یعنی تمام شده و 0 یعنی بدون خطا. کانتینر در حال اجرا Up … نشان می‌دهد
NAMESA random name Docker made up. Yours will be differentیک نام تصادفی که Docker ساخته. نام شما فرق می‌کند

Without -a, docker ps shows only running containers, so hello-world wouldn't be there. You may see other containers in your list too; the newest is at the top.

بدون -a، دستور docker ps فقط کانتینرهای در حال اجرا را نشان می‌دهد، پس hello-world در آن نیست. ممکن است کانتینرهای دیگری هم در فهرستتان ببینید؛ جدیدترین در بالاست.

3 Run it againاجرای دوباره Doneانجام شد

Repeat steps 1 and 2: run the image again, then list all containers. Each run makes a new container:

قدم‌های ۱ و ۲ را تکرار کنید: ایمیج را دوباره اجرا کنید و بعد همه‌ی کانتینرها را فهرست کنید. هر اجرا یک کانتینر جدید می‌سازد:

bash
docker run hello-world
docker ps -a
output
CONTAINER ID   IMAGE         COMMAND    CREATED         STATUS                     NAMES
5255154c4676   hello-world   "/hello"   4 seconds ago   Exited (0) 2 seconds ago   eager_cannon
978227142bc2   hello-world   "/hello"   8 seconds ago   Exited (0) 5 seconds ago   tender_visvesvaraya

Two containers, two IDs, two names, made from one image. That's the recipe and the cakes from Lesson 1.

دو کانتینر، دو شناسه، دو نام، از روی یک ایمیج. همان دستور پخت و کیک‌های درس ۱.

Checklistچک‌لیست

4 The image is now in useحالا ایمیج در حال استفاده است Doneانجام شد

bash
docker image ls hello-world
output
IMAGE                ID             DISK USAGE   CONTENT SIZE   EXTRA
hello-world:latest   5e2309035332       25.9kB         9.49kB   U

Remember the EXTRA column from Lesson 1? U means containers are using this image, even stopped ones. Docker won't let you delete an image while a container still needs it.

ستون EXTRA از درس ۱ یادتان هست؟ U یعنی کانتینرهایی از این ایمیج استفاده می‌کنند، حتی اگر متوقف باشند. تا وقتی کانتینری به ایمیج نیاز دارد، Docker اجازه‌ی حذف آن را نمی‌دهد.

Checklistچک‌لیست

5 Delete the containersحذف کانتینرها Doneانجام شد

Use docker rm with your container names (or IDs) from docker ps -a. You can give several at once:

از docker rm با نام‌ها (یا شناسه‌های) کانتینرهای خودتان از docker ps -a استفاده کنید. می‌توانید چند تا را با هم بدهید:

bash
docker rm tender_visvesvaraya eager_cannon   # use YOUR names
output
tender_visvesvaraya
eager_cannon

Now check both lists. The containers are gone, and the image is still there but no longer in use:

حالا هر دو فهرست را بررسی کنید. کانتینرها حذف شده‌اند و ایمیج هنوز هست، ولی دیگر در حال استفاده نیست:

bash
docker ps -a
docker image ls hello-world
output
IMAGE                ID             DISK USAGE   CONTENT SIZE   EXTRA
hello-world:latest   5e2309035332       25.9kB         9.49kB         # no U

🔑 docker rm deletes a container. docker image rm deletes an image. Don't mix them up.

🔑 docker rm یک کانتینر را حذف می‌کند. docker image rm یک ایمیج را. این دو را با هم اشتباه نگیرید.

💡 Shortcut: docker run --rm hello-world deletes the container automatically when it exits. That's what you used in Lesson 0.

💡 میان‌بُر: docker run --rm hello-world کانتینر را بعد از تمام شدن به‌طور خودکار حذف می‌کند. همان چیزی که در درس ۰ استفاده کردید.

Checklistچک‌لیست

6 Pick your own name with --nameانتخاب نام دلخواه با --name Doneانجام شد

Copying names like tender_visvesvaraya in step 5 was annoying, and they change every time. Give the container a name yourself:

کپی کردن نام‌هایی مثل tender_visvesvaraya در قدم ۵ آزاردهنده بود، و هر بار هم عوض می‌شوند. خودتان به کانتینر نام بدهید:

bash
docker run --name hello hello-world
docker ps -a
output
CONTAINER ID   IMAGE         COMMAND    CREATED         STATUS                     NAMES
5d317f21b58b   hello-world   "/hello"   4 seconds ago   Exited (0) 2 seconds ago   hello

Now you know the name in advance, so later commands are easy to type, and the same for everyone. Delete the container using its new name:

حالا نام را از قبل می‌دانید، پس دستورهای بعدی راحت تایپ می‌شوند و برای همه یکسان هستند. کانتینر را با نام جدیدش حذف کنید:

bash
docker rm hello
❓ What if I use the same name twice?❓ اگر یک نام را دو بار استفاده کنم چه می‌شود؟

Names must be unique. If a container called hello still exists (even stopped), Docker refuses:

نام‌ها باید یکتا باشند. اگر کانتینری به نام hello هنوز وجود داشته باشد (حتی متوقف)، Docker قبول نمی‌کند:

output
docker: Error response from daemon: Conflict. The container name "/hello" is already in use by container "c0daa80731df…". You have to remove (or rename) that container to be able to reuse that name.

Fix: docker rm hello first, then run again.

راه‌حل: اول docker rm hello، بعد دوباره اجرا کنید.

Checklistچک‌لیست

7 Delete all stopped containers at once: pruneحذف همه‌ی کانتینرهای متوقف با هم: prune Doneانجام شد

Copying names to delete containers one by one gets tiring. prune deletes all stopped containers in one go:

کپی کردن نام‌ها و حذف یکی‌یکی کانتینرها خسته‌کننده می‌شود. prune همه‌ی کانتینرهای متوقف را یک‌جا حذف می‌کند:

bash
docker container prune
output
WARNING! This will remove all stopped containers.
Are you sure you want to continue? [y/N]

It asks first. Type y and Enter to delete; it then lists the deleted container IDs and the disk space it freed. Anything else (or just Enter) cancels.

اول سؤال می‌پرسد. برای حذف y و Enter را بزنید؛ بعد شناسه‌ی کانتینرهای حذف‌شده و فضای آزادشده را نشان می‌دهد. هر چیز دیگری (یا فقط Enter) لغوش می‌کند.

⚠ “All” really means all: every stopped container on your PC, not only the ones from this course. Other projects' stopped containers, and everything inside them, are deleted too. Always run docker ps -a first and check the list. If you see anything you want to keep, answer N and delete by name with docker rm instead.

⚠ «همه» واقعاً یعنی همه: همه‌ی کانتینرهای متوقف روی کامپیوتر شما، نه فقط کانتینرهای این دوره. کانتینرهای متوقف پروژه‌های دیگر هم، با هر چه داخلشان است، حذف می‌شوند. همیشه اول docker ps -a را اجرا کنید و فهرست را بررسی کنید. اگر چیزی دیدید که می‌خواهید نگه دارید، N را بزنید و به‌جایش با docker rm و نام، حذف کنید.

Running containers are never touched; only stopped ones.

به کانتینرهای در حال اجرا دست نمی‌زند؛ فقط متوقف‌ها.

❓ Are there other prune commands?❓ دستورهای prune دیگری هم هست؟
docker container pruneall stopped containersهمه‌ی کانتینرهای متوقف
docker image pruneimages with no name (untagged)ایمیج‌های بدون نام (بدون تگ)
docker volume pruneunused volumes. ⚠ This can delete databases! (volumes: Lessons 8–9)volumeهای بلااستفاده. ⚠ این می‌تواند دیتابیس‌ها را حذف کند! (volumeها: درس‌های ۸ و ۹)
docker system pruneseveral of these at onceچند مورد از این‌ها با هم

They all ask before deleting, and they all work on your whole PC. Read the warning they print before answering y.

همه‌شان قبل از حذف سؤال می‌پرسند، و همه روی کل کامپیوتر شما کار می‌کنند. قبل از زدن y هشداری را که چاپ می‌کنند بخوانید.
