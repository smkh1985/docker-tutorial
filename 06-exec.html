Lesson 6 — Go inside a container درس ۶ — رفتن به داخل کانتینر

A container is like a small Linux machine. You'll open a shell inside the running nginx, look around, change its welcome page, and see your change in the browser.

کانتینر مثل یک ماشین لینوکس کوچک است. یک شل داخل nginx در حال اجرا باز می‌کنید، اطراف را می‌گردید، صفحه‌ی خوش‌آمد آن را تغییر می‌دهید و تغییرتان را در مرورگر می‌بینید.

🧠 Blurred commands are ones you've already learned. Try to remember them, then click to check.

🧠 دستورهای محو را قبلاً یاد گرفته‌اید. سعی کنید به یاد بیاورید، بعد کلیک کنید و ببینید.

1 Start nginxاجرای nginx Doneانجام شد

Start nginx in the background, named web, reachable at localhost:8080:

nginx را در پس‌زمینه، با نام web و در دسترس روی localhost:8080 اجرا کنید:

bash
docker run -d --name web -p 8080:80 nginx

Open http://localhost:8080 and keep the tab open. You should see “Welcome to nginx!”.

http://localhost:8080 را باز کنید و تب را باز نگه دارید. باید «Welcome to nginx!» را ببینید.

2 Go insideرفتن به داخل Doneانجام شد

bash
docker exec -it web bash
output
root@118989b0b06f:/#
exec
Execute: run a command inside a container that is already running.Execute: یک دستور را داخل کانتینری اجرا می‌کند که از قبل در حال اجراست.
-it
Interactive + terminal: so you can type into it. Needed for a shell.Interactive + terminal: تا بتوانید در آن تایپ کنید. برای شل لازم است.
bash
The command to run: a shell.دستوری که اجرا می‌شود: یک شل.

Your prompt changed. You are now inside the container, as root. The name after @ is the container's ID.

prompt شما عوض شد. حالا داخل کانتینر هستید، با کاربر root. نام بعد از @ شناسه‌ی کانتینر است.

3 Look aroundنگاهی به اطراف Doneانجام شد

nginx serves its web pages from the folder /usr/share/nginx/html. List it:

nginx صفحه‌های وب را از پوشه‌ی /usr/share/nginx/html سرو می‌کند. محتوایش را ببینید:

bash · inside
ls /usr/share/nginx/html
output
50x.html
index.html

index.html is the home page. Print it:

index.html صفحه‌ی اصلی است. چاپش کنید:

bash · inside
cat /usr/share/nginx/html/index.html
output
<!DOCTYPE html>
<html>
<head>
<title>Welcome to nginx!</title>
...

That's the page you see in the browser.

این همان صفحه‌ای است که در مرورگر می‌بینید.

Checklistچک‌لیست

4 Change the pageتغییر صفحه Doneانجام شد

Replace the page with your own one-line page:

صفحه را با یک صفحه‌ی یک‌خطی از خودتان عوض کنید:

bash · inside
echo '<h1>Hello from my container!</h1>' > /usr/share/nginx/html/index.html

echo prints the text, and > writes it into the file instead of the screen, replacing what was there.

💡 Note the single quotes '…'. With double quotes, the ! in the text confuses the shell and you get event not found. Single quotes pass the text exactly as written.

💡 به کوتیشن تکی '…' دقت کنید. با کوتیشن دوتایی، علامت ! در متن شل را گیج می‌کند و خطای event not found می‌گیرید. کوتیشن تکی متن را دقیقاً همان‌طور که نوشته شده می‌فرستد.

echo متن را چاپ می‌کند و > آن را به‌جای صفحه‌ی نمایش در فایل می‌نویسد و محتوای قبلی را جایگزین می‌کند.

Now reload the browser tab:

حالا تب مرورگر را reload کنید:

localhost:8080

Hello from my container!

❓ Why not open the file in an editor like nano?❓ چرا فایل را با ویرایشگری مثل nano باز نکنیم؟

The nginx image has no nano and no vi. Images are kept small, so they only contain what the app needs. Try nano: you'll get command not found.

ایمیج nginx نه nano دارد نه vi. ایمیج‌ها کوچک نگه داشته می‌شوند و فقط چیزهایی را دارند که برنامه لازم دارد. nano را امتحان کنید: خطای command not found می‌گیرید.

5 Come back outبیرون آمدن Doneانجام شد

bash · inside
exit

Your normal prompt is back. You left the shell. Is the container still running? Check it:

prompt معمولی شما برگشت. از شل خارج شدید. کانتینر هنوز در حال اجراست؟ بررسی کنید:

bash
docker ps

✅ web is still Up, and the browser still shows your page. exit closed only the shell that exec started, not the container. It's like Ctrl+C on docker logs -f in Lesson 5.

✅ web هنوز Up است و مرورگر هنوز صفحه‌ی شما را نشان می‌دهد. exit فقط شلی را بست که exec باز کرده بود، نه کانتینر را. مثل Ctrl+C روی docker logs -f در درس ۵.

Checklistچک‌لیست

6 Stop and start again: is my change still there?توقف و اجرای دوباره: تغییر من هنوز هست؟ Doneانجام شد

Stop the container:

کانتینر را متوقف کنید:

bash
docker stop web

Reload the browser. nginx isn't running, so there is no page:

مرورگر را reload کنید. nginx اجرا نمی‌شود، پس صفحه‌ای نیست:

localhost:8080

This site can't be reached

localhost refused to connect.

But the container still exists, only stopped (remember docker ps -a from Lesson 3). Start the same container again:

ولی کانتینر هنوز وجود دارد، فقط متوقف شده (docker ps -a در درس ۳ یادتان هست؟). همان کانتینر را دوباره روشن کنید:

bash
docker start web
output
web

Reload the browser:

مرورگر را reload کنید:

localhost:8080

Hello from my container!

✅ Your change is still there. Stopping a container doesn't delete it, so its files are kept.

✅ تغییر شما هنوز هست. متوقف کردن کانتینر آن را حذف نمی‌کند، پس فایل‌هایش باقی می‌مانند.

💡 docker start restarts an existing container, with the same name, port and files. docker run always creates a new one.

💡 docker start یک کانتینر موجود را دوباره روشن می‌کند، با همان نام، پورت و فایل‌ها. docker run همیشه یک کانتینر جدید می‌سازد.

Checklistچک‌لیست

7 Delete and run again: where did my change go?حذف و اجرای دوباره: تغییر من کجا رفت؟ Doneانجام شد

Now stop and delete web in one command:

حالا web را با یک دستور متوقف و حذف کنید:

bash
docker rm -f web

Create a new one, exactly like in step 1:

یک کانتینر جدید بسازید، دقیقاً مثل قدم ۱:

bash
docker run -d --name web -p 8080:80 nginx

Reload the browser:

مرورگر را reload کنید:

localhost:8080

Welcome to nginx!

If you see this page, nginx is successfully installed and working. …

Your page is gone! You changed the file in the container, not in the image. Deleting the container deleted the change. Every new container starts from the image, which never changed.

صفحه‌ی شما رفت! شما فایل را در کانتینر تغییر دادید، نه در ایمیج. با حذف کانتینر، تغییر هم حذف شد. هر کانتینر جدید از روی ایمیج ساخته می‌شود، و ایمیج هیچ‌وقت تغییر نکرد.

Imageایمیج nginxread-only · always “Welcome to nginx!”فقط‌خواندنی · همیشه «Welcome to nginx!»
docker run
Old containerکانتینر قبلیyour change · deletedتغییر شما · حذف شد
New containerکانتینر جدیدfresh copyنسخه‌ی تازه
Your changeتغییر شما
docker stop → docker start✅ kept: same containerباقی ماند: همان کانتینر
docker rm → docker run❌ lost: new container from the imageاز بین رفت: کانتینر جدید از روی ایمیج

🔑 Changes made inside a container live only as long as the container. Lesson 8 shows how to keep your changes.

🔑 تغییراتی که داخل کانتینر می‌دهید فقط تا وقتی کانتینر هست باقی می‌مانند. درس ۸ نشان می‌دهد چطور تغییراتتان را نگه دارید.

Clean up:

تمیزکاری:

bash
docker rm -f web
