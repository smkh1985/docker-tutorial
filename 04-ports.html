docker run -d --name web nginx

This site can’t be reached

🔒 WHY?چرا؟

A container has its own private network. nginx listens on port 80 inside the container, but nothing connects your PC to it. Even http://localhost:80 fails.هر کانتینر شبکه‌ی خصوصی خودش را دارد. nginx روی پورت 80 داخل کانتینر گوش می‌دهد، ولی چیزی کامپیوتر شما را به آن وصل نمی‌کند. حتی http://localhost:80 هم کار نمی‌کند.

Step 1 · Clean upقدم ۱ · پاک کردن

Stop and delete it: two waysتوقف و حذف: دو روش

Stop and delete web, so we can start it again the right way.web را متوقف و حذف کنید تا بتوانیم درست اجرایش کنیم.

Way 1 · two commandsروش ۱ · دو دستور
bash
docker stop web
web
docker rm web
web
Way 2 · shortcutروش ۲ · میان‌بُر
bash
docker rm -f web
web
💡 -f

-f (force) does both in one command. It stops the container if it's running, then deletes it.-f (force، یعنی اجباری) هر دو کار را با یک دستور انجام می‌دهد. اگر کانتینر در حال اجرا باشد متوقفش می‌کند و بعد حذفش می‌کند.

🔑

Use one way or the other, not both.یکی از این دو روش را استفاده کنید، نه هر دو را.

Step 2قدم ۲

Publish a port with -pمنتشر کردن پورت با ⁦-p⁩

Same command, plus -p 8080:80. -p means publish: it connects a port on your PC to a port inside the container.همان دستور، به‌اضافه‌ی -p 8080:80. -p یعنی publish (منتشر کردن): یک پورت روی کامپیوتر شما را به یک پورت داخل کانتینر وصل می‌کند.

bash
docker run -d --name web -p 8080:80 nginx
7ffd259c2bc0a4e1b9d35f0c8e27d6a14b3f9e0c52d871a6f4be093c2d1e58a7   # a container ID, no error
-p8080your PC (host)
you choose itکامپیوتر شما (host)
خودتان انتخابش می‌کنید:80inside the container
nginx listens here: fixedداخل کانتینر
nginx اینجا گوش می‌دهد: ثابت

The order is always your PC first, then the container.ترتیب همیشه این است: اول کامپیوتر شما، بعد کانتینر.

Step 2 · What if…قدم ۲ · اگر…

“Port is already allocated”?خطای «port is already allocated»؟

bash
docker run -d --name web -p 8080:80 nginx
docker: Error response from daemon: failed to set up container networking: ... Bind for 0.0.0.0:8080 failed: port is already allocated
🔌 ONE PORT, ONE PROGRAMیک پورت، یک برنامه

Something else on your PC (maybe another container) already uses port 8080. Only one program can use a host port at a time.برنامه‌ی دیگری روی کامپیوتر شما (شاید یک کانتینر دیگر) از پورت 8080 استفاده می‌کند. هر پورت host در هر لحظه فقط مال یک برنامه است.

✓ FIXراه‌حل

Delete the new container (docker rm web) and pick another host port, e.g. -p 8081:80, then open localhost:8081.کانتینر جدید را حذف کنید (docker rm web) و یک پورت دیگر انتخاب کنید، مثلاً -p 8081:80، و بعد localhost:8081 را باز کنید.
