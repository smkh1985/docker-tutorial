LESSON 17 · Dockerfileدرس ۱۷ · Dockerfile

You write down the steps. Anyone can read it and build exactly the same image again.مراحل را می‌نویسید. هر کسی می‌تواند آن را بخواند و دقیقاً همان ایمیج را دوباره بسازد.

Remember the recipe from Lesson 1? In Docker, that recipe file is called a Dockerfile. Today you write one.دستور پخت درس ۱ یادتان هست؟ در Docker به این فایل دستور پخت Dockerfile می‌گویند. امروز یکی می‌نویسید.

Step 1قدم ۱

Write a Dockerfileنوشتن Dockerfile

Go into your my-site folder from Lesson 10 and create a file named exactly Dockerfile:به پوشه‌ی my-site از درس ۱۰ بروید و فایلی با نام دقیقاً Dockerfile بسازید:

bash
cd ~/my-site
nano Dockerfile
Dockerfile · nano
FROM nginx
COPY index.html /usr/share/nginx/html/index.html

Save with Ctrl+O, Enter, and exit with Ctrl+X.با Ctrl+O و Enter ذخیره کنید و با Ctrl+X خارج شوید.

~/my-site
bash
ls
Dockerfile  index.html

No index.html? You skipped Lesson 10. Create it: echo '<h1>Changed on my PC!</h1>' > index.htmlindex.html ندارید؟ درس ۱۰ را رد کرده‌اید. بسازیدش: echo '<h1>Changed on my PC!</h1>' > index.html

Step 1 · Two linesقدم ۱ · دو خط

What the two lines doدو خط چه می‌کنند

Dockerfile
FROM nginx
COPY index.html /usr/share/nginx/html/index.html
FROM nginx

Start from the nginx imageاز ایمیج nginx شروع کن

Everything nginx has, your image has too.هر چه nginx دارد، ایمیج شما هم دارد.

COPY index.html …

Copy your page into the imageصفحه‌تان را داخل ایمیج کپی کن

Copy index.html from this folder into the image, where nginx looks for its home page.index.html را از این پوشه داخل ایمیج کپی کن، جایی که nginx صفحه‌ی اصلی را پیدا می‌کند.

Step 2 · The commandقدم ۲ · دستور

Build your imageساختن ایمیج

Still in ~/my-site, run:در همان ~/my-site اجرا کنید:

docker build -t my-site .
-t my-site

Tag: the name of your new image. No tag after it, so it becomes my-site:latest.Tag: نام ایمیج جدید شما. تگی بعدش نیامده، پس my-site:latest می‌شود.

.

This folder. Docker reads the Dockerfile here and can COPY files from here. Don't forget it!همین پوشه. Docker فایل Dockerfile را اینجا می‌خواند و فایل‌ها را از اینجا COPY می‌کند. فراموشش نکنید!

Steps 2–3قدم‌های ۲ و ۳

Docker follows your linesDocker خط‌های شما را دنبال می‌کند

bash · ~/my-site
docker build -t my-site .
 => [internal] load build definition from Dockerfile
 ...
 => [1/2] FROM docker.io/library/nginx:latest@sha256:f9ea18bfa4fad...  # line 1
 => [2/2] COPY index.html /usr/share/nginx/html/index.html              # line 2
 => exporting to image
 ...
 => => naming to docker.io/library/my-site:latest                       # your image's name
docker image ls my-site
IMAGE            ID             DISK USAGE   CONTENT SIZE   EXTRA
my-site:latest   6ba373bd396d        240MB         63.9MB

[1/2] and [2/2] are the two lines of your Dockerfile, run in order.[1/2] و [2/2] همان دو خط Dockerfile شما هستند که به ترتیب اجرا شدند.

The build finished with naming to … my-site:latest. ✅ساخت با naming to … my-site:latest تمام شد. ✅

Your own image, right next to the ones you pulled from Docker Hub.ایمیج خودتان، درست کنار ایمیج‌هایی که از Docker Hub دانلود کردید.

🔑 COPY

COPY made a copy of the file when you built the image. The image keeps that copy; it doesn't look at your folder anymore.COPY هنگام ساختن ایمیج از فایل یک کپی گرفت. ایمیج همان کپی را نگه می‌دارد و دیگر به پوشه‌ی شما نگاه نمی‌کند.

Step 6قدم ۶

Rebuild to updateساخت دوباره برای به‌روزرسانی

bash · ~/my-site
docker build -t my-site .
docker rm -f web
web
docker run -d --name web -p 8080:80 my-site
localhost:8080 ⟳

Version 2

🔑

To update an image: edit → build → replace the container.برای به‌روزرسانی ایمیج: ویرایش ← ساخت ← جایگزینی کانتینر.
