Settings with environment variablesتنظیمات با متغیرهای محیطی

Many ready-made images need settings before they can start: a password, a user name, a database name… You give them as environment variables, without changing the image.خیلی از ایمیج‌های آماده قبل از شروع به تنظیمات نیاز دارند: یک رمز عبور، یک نام کاربری، یک نام دیتابیس… این تنظیمات را به‌صورت متغیرهای محیطی به آن‌ها می‌دهید، بدون تغییر ایمیج.

Step 1قدم ۱

Run PostgreSQLاجرای PostgreSQL

PostgreSQL is one of the most used databases in the world. Start it in the background and name it db:PostgreSQL یکی از پراستفاده‌ترین دیتابیس‌های دنیاست. آن را در پس‌زمینه اجرا کنید و نامش را db بگذارید:

bash
docker run -d --name db postgres:alpine
# the first time it downloads the image (about 120 MB)
docker ps -a
NAMES     STATUS                       # other columns left out
db        Exited (1) 3 seconds ago
❌ Exited (1)

It stopped right away, and 1 means an error (0 was “OK” in Lesson 2).بلافاصله متوقف شد، و 1 یعنی خطا (در درس ۲، 0 یعنی «OK» بود).

Step 2قدم ۲

Why did it stop? Read the logsچرا متوقف شد؟ لاگ‌ها را بخوانید

When a container stops with an error, the first thing to do is read what it printed (Lesson 5):وقتی کانتینری با خطا متوقف می‌شود، اولین کار خواندن چیزی است که چاپ کرده (درس ۵):

bash
docker logs db
Error: Database is uninitialized and superuser password is not specified.
       You must specify POSTGRES_PASSWORD to a non-empty value for the
       superuser. For example, "-e POSTGRES_PASSWORD=password" on "docker run".
...
docker rm db
db
🔑

PostgreSQL refuses to start without a password, and it tells you exactly what to do: set POSTGRES_PASSWORD with -e.PostgreSQL بدون رمز عبور اجرا نمی‌شود، و دقیقاً می‌گوید چه کار کنید: POSTGRES_PASSWORD را با -e تنظیم کنید.

Step 3قدم ۳

Fix it with -eرفع با ‎-e

bash
docker run -d --name db -e POSTGRES_PASSWORD=secret postgres:alpine
35f390d3120d8b7a2c6e1f9d4b0a3c7e5f8d2b6a9c1e4f7b0d3a6c9e2f5b8d1a
docker ps
NAMES     STATUS          # other columns left out
db        Up 4 seconds
-eenvironment variableمتغیر محیطی POSTGRES_PASSWORDNAMEنام (NAME)=secretvalueمقدار (value)

-e means environment variable, written NAME=value. The program inside the container reads it when it starts.-e یعنی متغیر محیطی (environment variable)، به شکل NAME=value. برنامه‌ی داخل کانتینر هنگام شروع آن را می‌خواند.

✅ Up

The last line of docker logs db now says database system is ready to accept connections.آخرین خط docker logs db حالا می‌گوید database system is ready to accept connections.

💡 Docker Hub

Which variables does an image understand? Its page on Docker Hub lists them, e.g. POSTGRES_PASSWORD, POSTGRES_USER, POSTGRES_DB.یک ایمیج چه متغیرهایی را می‌فهمد؟ صفحه‌اش در Docker Hub آن‌ها را فهرست کرده، مثلاً POSTGRES_PASSWORD، POSTGRES_USER، POSTGRES_DB.

Step 4قدم ۴

See the variables inside the containerدیدن متغیرها داخل کانتینر

Run one command inside db: env lists all environment variables:یک دستور داخل db اجرا کنید: env همه‌ی متغیرهای محیطی را فهرست می‌کند:

bash
docker exec db env
PATH=/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin
HOSTNAME=35f390d3120d
POSTGRES_PASSWORD=secret              # ← yours, from -e
LANG=en_US.utf8
PG_VERSION=18.6                       # set by the image itself
PGDATA=/var/lib/postgresql/18/docker
...
docker rm -f db
db
YOURSمال شما

Your variable is there.متغیر شما آنجاست.

SET BY THE IMAGEتنظیم‌شده توسط ایمیج

The others were set by the image's authors, e.g. PG_VERSION. PGDATA is where PostgreSQL keeps its data: that's where a volume would go (Lesson 9).بقیه را سازندگان ایمیج تنظیم کرده‌اند، مثلاً PG_VERSION. PGDATA جایی است که PostgreSQL داده‌هایش را نگه می‌دارد: یک volume باید همان‌جا قرار بگیرد (درس ۹).

Step 5قدم ۵

Many settings? Use an env fileتنظیمات زیاد؟ از env file استفاده کنید

Let's also choose our own user name and database name. With -e the command gets long:بیایید نام کاربر و نام دیتابیس را هم خودمان انتخاب کنیم. با -e دستور طولانی می‌شود:

just look, don't runفقط نگاه کنید، اجرا نکنید
docker run -d --name db -e POSTGRES_USER=ali -e POSTGRES_PASSWORD=secret -e POSTGRES_DB=shop postgres:alpine

Instead, put the settings in a file, one NAME=value per line.به‌جای آن، تنظیمات را در یک فایل بگذارید، در هر خط یک NAME=value.

Step 5 · The fileقدم ۵ · فایل

Write db.envنوشتن db.env

Make a folder and create the file db.env:یک پوشه بسازید و فایل db.env را ایجاد کنید:

bash
mkdir ~/pg-demo
cd ~/pg-demo
nano db.env
GNU nano · db.env
1POSTGRES_USER=ali
2POSTGRES_PASSWORD=secret
3POSTGRES_DB=shop
SAVE AND EXITذخیره و خروج

Ctrl+O, Enter, Ctrl+X

🔑

No spaces around =, and no quotes.دور = فاصله نگذارید و از کوتیشن استفاده نکنید.

Step 5 · Run itقدم ۵ · اجرا

Run with --env-fileاجرا با ‎--env-file

bash · ~/pg-demo
docker run -d --name db --env-file db.env postgres:alpine
7c1e4a9f2b6d0e3c8a5f1b7d4e0a2c6f9b3d5e8a1c4f7b0d2e6a9c3f5b8d1e4a
docker exec db psql -U ali -d shop -c "SELECT current_user, current_database();"
 current_user | current_database
--------------+------------------
 ali          | shop
(1 row)

Short, and the settings are easy to read and change. Did they work? Ask PostgreSQL who you are and which database you're in (wait a few seconds for it to start first):کوتاه است و تنظیمات راحت خوانده و عوض می‌شوند. کار کرد؟ از PostgreSQL بپرسید شما کی هستید و در کدام دیتابیس هستید (اول چند ثانیه صبر کنید تا اجرا شود):

✅

User ali and database shop, both from db.env. (psql is PostgreSQL's command-line tool, like redis-cli in Lesson 9.)کاربر ali و دیتابیس shop، هر دو از db.env. (psql ابزار خط فرمان PostgreSQL است، مثل redis-cli در درس ۹.)

Step 6قدم ۶

Keep secrets safe, and clean upامن نگه داشتن رمزها، و تمیزکاری

Environment variables are not hidden. Anyone who can use Docker on this PC can read them:متغیرهای محیطی پنهان نیستند. هر کسی که روی این کامپیوتر به Docker دسترسی دارد می‌تواند آن‌ها را بخواند:

bash
docker inspect db
            "Env": [
                "POSTGRES_USER=ali",
                "POSTGRES_PASSWORD=secret",       # in plain text!
                "POSTGRES_DB=shop",
                ...
docker rm -f db
db
⚠

An env file holds passwords. Never put it in git or share it: add its name to .gitignore. Use real, strong passwords outside of practice.env file رمزهای عبور را در خود دارد. هرگز آن را در git نگذارید یا به اشتراک نگذارید: نامش را به .gitignore اضافه کنید. بیرون از تمرین از رمزهای واقعی و قوی استفاده کنید.

You can delete the image too (it's big): docker image rm postgres:alpine (Lesson 1).می‌توانید ایمیج را هم حذف کنید (بزرگ است): docker image rm postgres:alpine (درس ۱).
