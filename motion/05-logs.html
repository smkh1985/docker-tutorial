Logsلاگ‌ها

With -d, nginx's log seemed to disappear. It didn't: Docker keeps everything a container prints. You'll read it with docker logs, and even watch your own browser visits appear.با -d به نظر رسید که لاگ nginx ناپدید شد. ناپدید نشد: Docker هر چیزی را که کانتینر چاپ می‌کند نگه می‌دارد. آن را با docker logs می‌خوانید و حتی بازدیدهای مرورگر خودتان را در آن می‌بینید.

Step 3 · A first errorقدم ۳ · اولین خطا

What is the 404 line?خط 404 چیست؟

❓ favicon.ico · 404

Your browser also asks every website for a small icon to show on the tab, called favicon.ico. nginx's default site doesn't have one, so it answers 404 = Not Found and writes an [error] line. It's harmless, and a good first example of an error in a log.مرورگر شما از هر وب‌سایت یک آیکون کوچک هم برای نمایش روی تب می‌خواهد، به نام favicon.ico. سایت پیش‌فرض nginx این آیکون را ندارد، پس با 404 یعنی Not Found جواب می‌دهد و یک خط [error] می‌نویسد. بی‌خطر است و نمونه‌ی خوبی از یک خطا در لاگ است.

💡 LOG TOO LONG?💡 لاگ خیلی طولانی است؟

Show only the last lines with --tail, e.g.با --tail فقط خط‌های آخر را نشان دهید، مثلاً

docker logs --tail 3 web

Step 4قدم ۴

Follow the log liveدنبال کردن زنده‌ی لاگ

Running docker logs again and again is tiring. Add -f (follow) to keep watching:اجرای دوباره و دوباره‌ی docker logs خسته‌کننده است. -f (follow، یعنی دنبال کن) را اضافه کنید تا مدام تماشا کنید:

bash
docker logs -f web
...
172.17.0.1 - - [10/Oct/2026:09:38:58 +0000] "GET / HTTP/1.1" 200 896 "-" "Mozilla/5.0 …"
172.17.0.1 - - [10/Oct/2026:09:39:06 +0000] "GET / HTTP/1.1" 200 896 "-" "Mozilla/5.0 …"   # ← new, after a reload
172.17.0.1 - - [10/Oct/2026:09:39:09 +0000] "GET / HTTP/1.1" 200 896 "-" "Mozilla/5.0 …"   # ← new, after a reload
   ← waiting for more
^C
← your prompt is back

The terminal is stuck again, like in Lesson 3. Now reload the browser tab…ترمینال دوباره گیر کرده، مثل درس ۳. حالا تب مرورگر را reload کنید…

When you're done watching, press Ctrl+C to get your terminal back.وقتی تماشا تمام شد، Ctrl+C را بزنید تا ترمینال به شما برگردد.

Step 6قدم ۶

Clean upتمیزکاری

bash
docker rm -f web
web
docker ps -a
CONTAINER ID   IMAGE     COMMAND   CREATED   STATUS    PORTS     NAMES
🔑

The logs are stored with the container. Once you delete it, its logs are gone too.لاگ‌ها همراه کانتینر ذخیره می‌شوند. وقتی کانتینر را حذف کنید، لاگ‌هایش هم حذف می‌شوند.

Summaryخلاصه

🎉 You can read a container's logs!🎉 حالا می‌توانید لاگ‌های کانتینر را بخوانید!
