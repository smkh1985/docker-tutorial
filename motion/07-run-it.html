Step 2قدم ۲

Why --rm?چرا ⁦--rm⁩؟

bash
docker run --name once alpine echo hi
hi
docker ps -a
NAMES     STATUS                     # other columns left out
once      Exited (0) 1 second ago
docker rm once
once

A leftover. Every one-off command would leave one behind. Delete it:یک باقی‌مانده. هر دستور یک‌باره یکی از این‌ها جا می‌گذارد. حذفش کنید:

🔑 For one-off commands, always add --rm.🔑 برای دستورهای یک‌باره همیشه --rm را اضافه کنید.

Step 3قدم ۳

A shell in a new containerیک شل در کانتینر جدید

Want to look around Ubuntu without installing it? Run bash in a new ubuntu container, with -it so you can type (like exec -it in Lesson 6):می‌خواهید بدون نصب، Ubuntu را بگردید؟ bash را در یک کانتینر جدید ubuntu اجرا کنید، با -it تا بتوانید تایپ کنید (مثل exec -it در درس ۶):

bash
docker run -it --rm ubuntu bash
root@e51c490f4f10:/#   # inside a fresh Ubuntu
cat /etc/os-release
PRETTY_NAME="Ubuntu 26.04.1 LTS"
NAME="Ubuntu"
...
exit
exit

🔑 The shell was the container's program, so leaving it stopped the container, and --rm deleted it. Check: docker ps -a has no Ubuntu container.🔑 شل همان برنامه‌ی کانتینر بود، پس خروج از آن کانتینر را متوقف کرد و --rm حذفش کرد. بررسی کنید: docker ps -a هیچ کانتینر Ubuntu ندارد.

Step 3 · A questionقدم ۳ · یک سؤال

What if I forget -it?اگر ⁦-it⁩ را فراموش کنم؟

bash
docker run --rm ubuntu bash
$   ← back immediately: no prompt, no error
❓ -it

docker run --rm ubuntu bash returns immediately, with no prompt and no error. bash had no keyboard to read from, so it had nothing to do and exited. Interactive programs need -it.docker run --rm ubuntu bash بلافاصله برمی‌گردد، بدون prompt و بدون خطا. bash صفحه‌کلیدی برای خواندن نداشت، پس کاری برای انجام نداشت و تمام شد. برنامه‌های تعاملی -it لازم دارند.

Step 4قدم ۴

run -it or exec -it?⁦run -it⁩ یا ⁦exec -it⁩؟

Both give you a shell, but in very different containers:هر دو یک شل به شما می‌دهند، ولی در کانتینرهای خیلی متفاوت:

docker exec -it NAME bash
docker run -it --rm IMAGE bash
Containerکانتینر
an existing, running one (Lesson 6)یک کانتینر موجود و در حال اجرا (درس ۶)
a brand-new one, from an imageیک کانتینر کاملاً جدید، از روی ایمیج
After exitبعد از exit
the container keeps runningکانتینر روشن می‌ماند
the container stops (and --rm deletes it)کانتینر متوقف می‌شود (و --rm حذفش می‌کند)
Use it toکاربرد
look inside / fix a running appنگاه کردن داخل / رفع مشکل برنامه‌ی در حال اجرا
try an image, run a quick toolامتحان یک ایمیج، اجرای سریع یک ابزار

You can delete the images you pulled if you like (Lesson 1): docker image rm alpine ubuntuاگر خواستید، ایمیج‌هایی را که دانلود کردید حذف کنید (درس ۱): docker image rm alpine ubuntu
