Step 1قدم ۱

Run itاجرا

bash
docker run hello-world
Hello from Docker!
This message shows that your installation appears to be working correctly.
...
TWO THINGSدو کار

docker run created a new container from the image, and started it.docker run از روی ایمیج یک کانتینر جدید ساخت و آن را اجرا کرد.

THEN IT STOPPEDبعد متوقف شد

The program inside printed the message and finished, so the container stopped.برنامه‌ی داخل آن پیام را چاپ کرد و تمام شد، پس کانتینر هم متوقف شد.

❓ DID IT DOWNLOAD AGAIN?دوباره دانلود کرد؟

No. The message text about Docker Hub is always the same. The image was already on your PC from Lesson 1, so there was no Unable to find image … locally line at the top.نه. متن پیام درباره‌ی Docker Hub همیشه ثابت است. ایمیج از درس ۱ روی کامپیوتر شما بود، پس خط Unable to find image … locally در بالای خروجی نیامد.

Step 2قدم ۲

See the containerدیدن کانتینر

The container stopped, but it still exists. List all containers, including stopped ones:کانتینر متوقف شده، ولی هنوز وجود دارد. همه‌ی کانتینرها را، حتی متوقف‌شده‌ها، فهرست کنید:

bash
docker ps -a
CONTAINER ID   IMAGE         COMMAND    CREATED         STATUS                     NAMES
978227142bc2   hello-world   "/hello"   4 seconds ago   Exited (0) 2 seconds ago   tender_visvesvaraya
CONTAINER ID

The container's unique IDشناسه‌ی یکتای کانتینر

IMAGE

The image it was made fromایمیجی که کانتینر از روی آن ساخته شده

STATUS

Exited (0) = finished, and 0 means no error. A running container shows Up …Exited (0) یعنی تمام شده و 0 یعنی بدون خطا. کانتینر در حال اجرا Up … نشان می‌دهد

NAMES

A random name Docker made up. Yours will be differentیک نام تصادفی که Docker ساخته. نام شما فرق می‌کند

-a

Without -a, docker ps shows only running containers, so hello-world wouldn't be there. You may see other containers in your list too; the newest is at the top.بدون -a، دستور docker ps فقط کانتینرهای در حال اجرا را نشان می‌دهد، پس hello-world در آن نیست. ممکن است کانتینرهای دیگری هم در فهرستتان ببینید؛ جدیدترین در بالاست.

Step 3قدم ۳

Run it againاجرای دوباره

Repeat steps 1 and 2. Each run makes a new container:قدم‌های ۱ و ۲ را تکرار کنید. هر اجرا یک کانتینر جدید می‌سازد:

bash
docker run hello-world
Hello from Docker!
...
docker ps -a
CONTAINER ID   IMAGE         COMMAND    CREATED         STATUS                     NAMES
5255154c4676   hello-world   "/hello"   4 seconds ago   Exited (0) 2 seconds ago   eager_cannon
978227142bc2   hello-world   "/hello"   8 seconds ago   Exited (0) 5 seconds ago   tender_visvesvaraya
🔑

Two containers, two IDs, two names, made from one image.دو کانتینر، دو شناسه، دو نام، از روی یک ایمیج.

Step 4قدم ۴

The image is now in useحالا ایمیج در حال استفاده است

bash
docker image ls hello-world
IMAGE                ID             DISK USAGE   CONTENT SIZE   EXTRA
hello-world:latest   5e2309035332       25.9kB         9.49kB   U
EXTRA · U

Remember the EXTRA column from Lesson 1? U means containers are using this image, even stopped ones.ستون EXTRA از درس ۱ یادتان هست؟ U یعنی کانتینرهایی از این ایمیج استفاده می‌کنند، حتی اگر متوقف باشند.

🔒

Docker won't let you delete an image while a container still needs it.تا وقتی کانتینری به ایمیج نیاز دارد، Docker اجازه‌ی حذف آن را نمی‌دهد.

Step 5قدم ۵

Delete the containersحذف کانتینرها

bash
docker rm tender_visvesvaraya eager_cannon
tender_visvesvaraya
eager_cannon
docker ps -a
CONTAINER ID   IMAGE     COMMAND   CREATED   STATUS    NAMES
docker image ls hello-world
IMAGE                ID             DISK USAGE   CONTENT SIZE   EXTRA
hello-world:latest   5e2309035332       25.9kB         9.49kB
# EXTRA is empty now: no U
🔑

docker rm deletes a container. docker image rm deletes an image. Don't mix them up.docker rm یک کانتینر را حذف می‌کند. docker image rm یک ایمیج را. این دو را با هم اشتباه نگیرید.

💡 SHORTCUTمیان‌بُر

docker run --rm hello-world deletes the container automatically when it exits. You used it in Lesson 0.docker run --rm hello-world کانتینر را بعد از تمام شدن به‌طور خودکار حذف می‌کند. در درس ۰ از آن استفاده کردید.

Use docker rm with your container names (or IDs) from docker ps -a. You can give several at once.از docker rm با نام‌ها (یا شناسه‌های) کانتینرهای خودتان از docker ps -a استفاده کنید. می‌توانید چند تا را با هم بدهید.

Step 6قدم ۶

Pick your own name with --nameانتخاب نام دلخواه با ⁦--name⁩

Copying names like tender_visvesvaraya was annoying, and they change every time. Give the container a name yourself:کپی کردن نام‌هایی مثل tender_visvesvaraya آزاردهنده بود، و هر بار هم عوض می‌شوند. خودتان به کانتینر نام بدهید:

bash
docker run --name hello hello-world
Hello from Docker!
...
docker ps -a
CONTAINER ID   IMAGE         COMMAND    CREATED         STATUS                     NAMES
5d317f21b58b   hello-world   "/hello"   4 seconds ago   Exited (0) 2 seconds ago   hello
docker rm hello
hello
NAMES

Now you know the name in advance, so later commands are easy to type, and the same for everyone.حالا نام را از قبل می‌دانید، پس دستورهای بعدی راحت تایپ می‌شوند و برای همه یکسان هستند.

❓ SAME NAME TWICE?یک نام، دو بار؟

Names must be unique. If hello still exists (even stopped), Docker refuses. Fix: docker rm hello first.نام‌ها باید یکتا باشند. اگر hello هنوز وجود داشته باشد (حتی متوقف)، Docker قبول نمی‌کند. راه‌حل: اول docker rm hello.

docker: Error response from daemon: Conflict. The container name "/hello" is already in use by container "c0daa80731df…".
Step 7قدم ۷

All stopped containers at once: pruneهمه‌ی کانتینرهای متوقف با هم: prune

bash
docker container prune
WARNING! This will remove all stopped containers.
Are you sure you want to continue? [y/N]
[y/N]

It asks first. Type y and Enter to delete; it then lists the deleted container IDs and the disk space it freed. Anything else (or just Enter) cancels.اول سؤال می‌پرسد. برای حذف y و Enter را بزنید؛ بعد شناسه‌ی کانتینرهای حذف‌شده و فضای آزادشده را نشان می‌دهد. هر چیز دیگری (یا فقط Enter) لغوش می‌کند.

⚠ “ALL” REALLY MEANS ALL«همه» واقعاً یعنی همه

Every stopped container on your PC, not only the ones from this course. Always run docker ps -a first and check the list. Want to keep something? Answer N and delete by name with docker rm.همه‌ی کانتینرهای متوقف روی کامپیوتر شما، نه فقط کانتینرهای این دوره. همیشه اول docker ps -a را اجرا کنید و فهرست را بررسی کنید. چیزی می‌خواهید نگه دارید؟ N را بزنید و با docker rm و نام حذف کنید.

❓ OTHER prune COMMANDSدستورهای prune دیگر
docker image pruneimages with no name (untagged)ایمیج‌های بدون نام (بدون تگ)
docker volume pruneunused volumes ⚠ can delete databases (Lessons 8–9)volumeهای بلااستفاده ⚠ می‌تواند دیتابیس‌ها را حذف کند (درس‌های ۸ و ۹)
docker system pruneseveral of these at onceچند مورد از این‌ها با هم

All ask first, and all work on your whole PC.همه اول سؤال می‌پرسند، و همه روی کل کامپیوتر شما کار می‌کنند.
