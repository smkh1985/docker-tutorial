Docker ComposeDocker Compose

Write all your container settings in a file once, then start everything with one short command.همه‌ی تنظیمات کانتینرتان را یک بار در یک فایل بنویسید و بعد همه‌چیز را با یک دستور کوتاه اجرا کنید.

Press → or Space to startبرای شروع → یا Space را بزنید

Why Compose?چرا Compose؟

Your commands keep getting longerدستورهای شما مدام طولانی‌تر می‌شوند

Remember this one from Lesson 10?این یکی از درس ۱۰ یادتان هست؟

docker run -d --name web -p 8080:80 -v ~/my-site:/usr/share/nginx/html nginx
😵 Hard to remember😵 به خاطر سپردنش سخت است
⌨️ Easy to mistype⌨️ راحت اشتباه تایپ می‌شود
📤 Hard to share📤 اشتراکش سخت است

Docker Compose lets you write all of it in a file once, then start everything with one short command.Docker Compose اجازه می‌دهد همه‌ی این‌ها را یک بار در یک فایل بنویسید و بعد همه‌چیز را با یک دستور کوتاه اجرا کنید.

Step 1قدم ۱

Make a project folderساختن پوشه‌ی پروژه

A Compose project lives in its own folder. Make ~/compose-demo with an html folder inside, and go into it.هر پروژه‌ی Compose در پوشه‌ی خودش است. پوشه‌ی ~/compose-demo را با یک پوشه‌ی html داخلش بسازید و واردش شوید.

bash
mkdir -p ~/compose-demo/html
cd ~/compose-demo
echo '<h1>Hello from Compose!</h1>' > html/index.html
YOUR PCکامپیوتر شما
📁compose-demo/you are hereاینجا هستید
📁html/
📄index.html
Step 2قدم ۲

Write compose.yamlنوشتن compose.yaml

bash
nano compose.yaml
compose.yaml
services:
··web:
····image: nginx
····ports:
······- "8080:80"
····volumes:
······- ./html:/usr/share/nginx/html
MIND THE SPACESبه فاصله‌ها دقت کنید

Type it with exactly these spaces. YAML uses indentation, like Python. (The · dots here just show you the spaces.)این را دقیقاً با همین فاصله‌ها تایپ کنید. YAML مثل Python از تورفتگی استفاده می‌کند. (نقطه‌های · اینجا فقط فاصله‌ها را نشان می‌دهند.)

SAVE AND EXITذخیره و خروج

Save: Ctrl + O, Enter. Exit: Ctrl + X.ذخیره: Ctrl + O و Enter. خروج: Ctrl + X.

Step 2 · Read the fileقدم ۲ · خواندن فایل

Every line matches the old docker runهر خط با docker run قبلی جور است

docker run -d --name web -p 8080:80 -v ~/my-site:/usr/share/nginx/html nginx
compose.yaml
services:
web:
image: nginx
ports:
- "8080:80"
volumes:
- ./html:/usr/share/nginx/html

Press → to match each line of the file to a part of the command.→ را بزنید تا هر خط فایل را به بخشی از دستور وصل کنید.

services:

The list of containers in this project.فهرست کانتینرهای این پروژه.

web:↔--name web

One service, called web.یک سرویس به نام web.

image: nginx↔nginx

The image to run.ایمیجی که اجرا می‌شود.

ports: - "8080:80"↔-p 8080:80

Publish a port (Lesson 4).منتشر کردن پورت (درس ۴).

volumes: - ./html:…↔-v …:…

Share a folder (Lessons 8 and 10). ./html = the html folder next to this file.اشتراک پوشه (درس‌های ۸ و ۱۰). ./html یعنی پوشه‌ی html کنار همین فایل.

-d?

No -d here: that goes on the command in the next step.-d اینجا نیست: در دستور قدم بعد می‌آید.

Step 3قدم ۳

Start it: docker compose upاجرا: docker compose up

In the same folder as compose.yaml, run it. -d means the same as in Lesson 3: run in the background.در همان پوشه‌ای که compose.yaml هست اجرا کنید. -d همان معنی درس ۳ را دارد: اجرا در پس‌زمینه.

bash
docker compose up -d
[+] up 2/2
 ✔ Network compose-demo_default Created       # a network, made for you (Lesson 13)
 ✔ Container compose-demo-web-1 Started       # your container
1 · NETWORK۱ · شبکه

Created a network for the project, compose-demo_default, named after the folder.یک شبکه برای پروژه ساخت، compose-demo_default، که از نام پوشه می‌آید.

2 · CONTAINER۲ · کانتینر
compose-demo-web-1

Created and started: folder name, service name, number.ساخته و اجرا شد: نام پوشه، نام سرویس، شماره.

Step 4قدم ۴

Check itبررسی

List this project's containers. Like docker ps, but only for this project:کانتینرهای این پروژه را فهرست کنید. مثل docker ps، ولی فقط برای همین پروژه:

bash
docker compose ps
NAME                 IMAGE     SERVICE   STATUS         PORTS
compose-demo-web-1   nginx     web       Up 2 seconds   0.0.0.0:8080->80/tcp, [::]:8080->80/tcp
localhost:8080

Hello from Compose!

It's a normal container. Everything you learned still works on it, e.g. docker logs compose-demo-web-1.یک کانتینر معمولی است. هر چه یاد گرفتید رویش کار می‌کند، مثلاً docker logs compose-demo-web-1.

Step 5قدم ۵

Stop it: docker compose downتوقف: docker compose down

bash
docker compose down
 Container compose-demo-web-1 Removed
 Network compose-demo_default Removed
docker ps -a
CONTAINER ID   IMAGE     COMMAND   CREATED   STATUS    PORTS     NAMES
# compose-demo-web-1 is gone

🔑 With Compose, the whole setup lives in compose.yaml. up -d to start, down to remove. Run docker compose up -d again any time: same result, nothing to remember.🔑 با Compose، کل تنظیمات در compose.yaml است. up -d برای اجرا، down برای حذف. هر وقت خواستید دوباره docker compose up -d بزنید: همان نتیجه، بدون نیاز به حفظ کردن چیزی.

One command stopped and deleted the container and the network. Your html folder is untouched (Lesson 8).یک دستور کانتینر و شبکه را متوقف و حذف کرد. پوشه‌ی html شما دست‌نخورده می‌ماند (درس ۸).
