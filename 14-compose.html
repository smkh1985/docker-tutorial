Lesson 14 — Docker Compose درس ۱۴ — Docker Compose

Your docker run commands keep getting longer. Remember this one from Lesson 10?

دستورهای docker run شما مدام طولانی‌تر می‌شوند. این یکی از درس ۱۰ یادتان هست؟

bash
docker run -d --name web -p 8080:80 -v ~/my-site:/usr/share/nginx/html nginx

Hard to remember, easy to mistype, hard to share. Docker Compose lets you write all of it in a file once, then start everything with one short command.

به خاطر سپردنش سخت است، راحت اشتباه تایپ می‌شود و اشتراکش سخت است. Docker Compose اجازه می‌دهد همه‌ی این‌ها را یک بار در یک فایل بنویسید و بعد همه‌چیز را با یک دستور کوتاه اجرا کنید.

🧠 Blurred commands are ones you've already learned. Try to remember them, then click to check.

🧠 دستورهای محو را قبلاً یاد گرفته‌اید. سعی کنید به یاد بیاورید، بعد کلیک کنید و ببینید.

1 Make a project folderساختن پوشه‌ی پروژه Doneانجام شد

A Compose project lives in its own folder. Make ~/compose-demo with an html folder inside, and go into it:

هر پروژه‌ی Compose در پوشه‌ی خودش است. پوشه‌ی ~/compose-demo را با یک پوشه‌ی html داخلش بسازید و واردش شوید:

bash
mkdir -p ~/compose-demo/html
cd ~/compose-demo

Put a page in html/index.html with the text <h1>Hello from Compose!</h1>:

یک صفحه با متن <h1>Hello from Compose!</h1> در html/index.html بگذارید:

bash
echo '<h1>Hello from Compose!</h1>' > html/index.html
Checklistچک‌لیست

2 Write compose.yamlنوشتن compose.yaml Doneانجام شد

bash
nano compose.yaml

Type this, with exactly these spaces (YAML uses indentation, like Python):

این را تایپ کنید، دقیقاً با همین فاصله‌ها (YAML مثل Python از تورفتگی استفاده می‌کند):

compose.yaml
services:
  web:
    image: nginx
    ports:
      - "8080:80"
    volumes:
      - ./html:/usr/share/nginx/html

Save (Ctrl+O, Enter) and exit (Ctrl+X). Every line matches a part of the old docker run:

ذخیره کنید (Ctrl+O و Enter) و خارج شوید (Ctrl+X). هر خط با بخشی از docker run قبلی جور است:

compose.yaml docker run Meaningمعنی
services:The list of containers in this projectفهرست کانتینرهای این پروژه
web:--name webOne service, called webیک سرویس به نام web
image: nginxnginxThe image to runایمیجی که اجرا می‌شود
ports: - "8080:80"-p 8080:80Publish a port (Lesson 4)منتشر کردن پورت (درس ۴)
volumes: - ./html:…-v …:…Share a folder (Lessons 8 and 10). ./html = the html folder next to this fileاشتراک پوشه (درس‌های ۸ و ۱۰). ./html یعنی پوشه‌ی html کنار همین فایل

No -d here: that goes on the command in the next step.

-d اینجا نیست: در دستور قدم بعد می‌آید.

3 Start it: docker compose upاجرا: docker compose up Doneانجام شد

In the same folder as compose.yaml, run:

در همان پوشه‌ای که compose.yaml هست اجرا کنید:

bash
docker compose up -d
output
[+] up 2/2
 ✔ Network compose-demo_default Created       # a network, made for you (Lesson 13)
 ✔ Container compose-demo-web-1 Started       # your container

-d means the same as in Lesson 3: run in the background. Compose did two things for you:

-d همان معنی درس ۳ را دارد: اجرا در پس‌زمینه. Compose دو کار برایتان کرد:

  • Created a network for the project, compose-demo_default, named after the folder.یک شبکه برای پروژه ساخت، compose-demo_default، که از نام پوشه می‌آید.
  • Created and started the container compose-demo-web-1: folder name, service name, number.کانتینر compose-demo-web-1 را ساخت و اجرا کرد: نام پوشه، نام سرویس، شماره.

4 Check itبررسی Doneانجام شد

List this project's containers:

کانتینرهای این پروژه را فهرست کنید:

bash
docker compose ps
output
NAME                 IMAGE     SERVICE   STATUS         PORTS
compose-demo-web-1   nginx     web       Up 2 seconds   0.0.0.0:8080->80/tcp, [::]:8080->80/tcp

Like docker ps, but only for this project. Open http://localhost:8080:

مثل docker ps، ولی فقط برای همین پروژه. http://localhost:8080 را باز کنید:

localhost:8080

Hello from Compose!

It's a normal container. Everything you learned still works on it, e.g. docker logs compose-demo-web-1.

یک کانتینر معمولی است. هر چه یاد گرفتید رویش کار می‌کند، مثلاً docker logs compose-demo-web-1.

Checklistچک‌لیست

5 Stop it: docker compose downتوقف: docker compose down Doneانجام شد

bash
docker compose down
output
 Container compose-demo-web-1 Removed
 Network compose-demo_default Removed

One command stopped and deleted the container and the network. Check that the container is gone from all containers:

یک دستور کانتینر و شبکه را متوقف و حذف کرد. بررسی کنید که کانتینر از همه‌ی کانتینرها حذف شده:

bash
docker ps -a

🔑 With Compose, the whole setup lives in compose.yaml. up -d to start, down to remove. Run docker compose up -d again any time: same result, nothing to remember. Your html folder is untouched (Lesson 8).

🔑 با Compose، کل تنظیمات در compose.yaml است. up -d برای اجرا، down برای حذف. هر وقت خواستید دوباره docker compose up -d بزنید: همان نتیجه، بدون نیاز به حفظ کردن چیزی. پوشه‌ی html شما دست‌نخورده می‌ماند (درس ۸).
