Lesson 17 — Your first Dockerfile درس ۱۷ — اولین Dockerfile شما

In Lesson 16 you made an image by hand with commit, but nobody could see what was inside or repeat it. A Dockerfile fixes that: you write down the steps, and Docker builds the image from them. Anyone can read it and build exactly the same image again.

در درس ۱۶ با commit یک ایمیج را با دست ساختید، ولی هیچ‌کس نمی‌توانست ببیند داخلش چیست یا آن را تکرار کند. Dockerfile این را حل می‌کند: مراحل را می‌نویسید و Docker ایمیج را از روی آن‌ها می‌سازد. هر کسی می‌تواند آن را بخواند و دقیقاً همان ایمیج را دوباره بسازد.

1 Write a Dockerfileنوشتن Dockerfile Doneانجام شد

Go into your my-site folder from Lesson 10 and create a file named exactly Dockerfile:

به پوشه‌ی my-site از درس ۱۰ بروید و فایلی با نام دقیقاً Dockerfile بسازید:

bash
cd ~/my-site
nano Dockerfile

Type these two lines:

این دو خط را تایپ کنید:

Dockerfile
FROM nginx
COPY index.html /usr/share/nginx/html/index.html

Save with Ctrl+O, Enter, and exit with Ctrl+X.

با Ctrl+O و Enter ذخیره کنید و با Ctrl+X خارج شوید.

FROM nginxStart from the nginx image. Everything nginx has, your image has tooاز ایمیج nginx شروع کن. هر چه nginx دارد، ایمیج شما هم دارد
COPY index.html …Copy index.html from this folder into the image, where nginx looks for its home pageindex.html را از این پوشه داخل ایمیج کپی کن، جایی که nginx صفحه‌ی اصلی را پیدا می‌کند

Check the folder. You should see both files:

پوشه را بررسی کنید. باید هر دو فایل را ببینید:

bash
ls
output
Dockerfile  index.html

No index.html? You skipped Lesson 10. Create it: echo '<h1>Changed on my PC!</h1>' > index.html

index.html ندارید؟ درس ۱۰ را رد کرده‌اید. بسازیدش: echo '<h1>Changed on my PC!</h1>' > index.html

2 Build your imageساختن ایمیج Doneانجام شد

Still in ~/my-site, run:

در همان ~/my-site اجرا کنید:

bash
docker build -t my-site .
-t my-site
Tag: the name of your new image. No tag after it, so it becomes my-site:latest.Tag: نام ایمیج جدید شما. تگی بعدش نیامده، پس my-site:latest می‌شود.
.
This folder. Docker reads the Dockerfile here and can COPY files from here. Don't forget it!همین پوشه. Docker فایل Dockerfile را اینجا می‌خواند و فایل‌ها را از اینجا COPY می‌کند. فراموشش نکنید!
output
 => [internal] load build definition from Dockerfile
 ...
 => [1/2] FROM docker.io/library/nginx:latest@sha256:f9ea18bfa4fad...   # line 1 of your Dockerfile
 => [2/2] COPY index.html /usr/share/nginx/html/index.html               # line 2
 => exporting to image
 ...
 => => naming to docker.io/library/my-site:latest                        # your image's name

[1/2] and [2/2] are the two lines of your Dockerfile, run in order.

[1/2] و [2/2] همان دو خط Dockerfile شما هستند که به ترتیب اجرا شدند.

3 See your imageدیدن ایمیج Doneانجام شد

List only the my-site image, like you did with hello-world in Lesson 1:

فقط ایمیج my-site را فهرست کنید، مثل کاری که در درس ۱ با hello-world کردید:

bash
docker image ls my-site
output
IMAGE            ID             DISK USAGE   CONTENT SIZE   EXTRA
my-site:latest   6ba373bd396d        240MB         63.9MB

Your own image, right next to the ones you pulled from Docker Hub.

ایمیج خودتان، درست کنار ایمیج‌هایی که از Docker Hub دانلود کردید.

4 Run it, without -vاجرای آن، بدون -v Doneانجام شد

Run your image in the background, named web, on localhost:8080. Use my-site instead of nginx, and no -v:

ایمیج خودتان را در پس‌زمینه، با نام web و روی localhost:8080 اجرا کنید. به‌جای nginx از my-site استفاده کنید، و بدون -v:

bash
docker run -d --name web -p 8080:80 my-site

Open http://localhost:8080:

http://localhost:8080 را باز کنید:

localhost:8080

Changed on my PC!

Your page, with no -v. It's inside the image.

صفحه‌ی شما، بدون -v. داخل ایمیج است.

5 Edit the page on your PC: does it change?ویرایش صفحه روی کامپیوتر: تغییر می‌کند؟ Doneانجام شد

In Lesson 10 this changed the page right away. Replace the text in index.html with <h1>Version 2</h1>:

در درس ۱۰ این کار صفحه را بلافاصله عوض کرد. متن index.html را با <h1>Version 2</h1> جایگزین کنید:

bash
echo '<h1>Version 2</h1>' > index.html

Reload the browser:

مرورگر را reload کنید:

localhost:8080

Changed on my PC!

No change! COPY made a copy of the file when you built the image. The image keeps that copy; it doesn't look at your folder anymore.

تغییری نکرد! COPY هنگام ساختن ایمیج از فایل یک کپی گرفت. ایمیج همان کپی را نگه می‌دارد و دیگر به پوشه‌ی شما نگاه نمی‌کند.

6 Rebuild to updateساخت دوباره برای به‌روزرسانی Doneانجام شد

Build the image again, so it gets a fresh copy of index.html:

ایمیج را دوباره بسازید تا یک کپی تازه از index.html بگیرد:

bash
docker build -t my-site .

The running container still uses the old image. Replace it: delete web in one command, then run your image again like in step 4:

کانتینر در حال اجرا هنوز از ایمیج قبلی استفاده می‌کند. عوضش کنید: web را با یک دستور حذف کنید و بعد ایمیج‌تان را مثل قدم ۴ دوباره اجرا کنید:

bash
docker rm -f web
docker run -d --name web -p 8080:80 my-site

Reload the browser:

مرورگر را reload کنید:

localhost:8080

Version 2

🔑 To update an image: edit → build → replace the container.

🔑 برای به‌روزرسانی ایمیج: ویرایش ← ساخت ← جایگزینی کانتینر.
