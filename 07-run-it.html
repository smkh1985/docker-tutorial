Lesson 7 — Run a command in a new container درس ۷ — اجرای یک دستور در کانتینر جدید

Every image has a default program: nginx starts a web server, hello-world prints a message. But you can tell docker run to run your own command instead. Great for trying a Linux distro or running a quick tool, without installing anything.

هر ایمیج یک برنامه‌ی پیش‌فرض دارد: nginx یک وب‌سرور اجرا می‌کند، hello-world یک پیام چاپ می‌کند. ولی می‌توانید به docker run بگویید به‌جای آن دستور خودتان را اجرا کند. عالی برای امتحان یک توزیع لینوکس یا اجرای سریع یک ابزار، بدون نصب هیچ چیز.

🧠 Blurred commands are ones you've already learned. Try to remember them, then click to check.

🧠 دستورهای محو را قبلاً یاد گرفته‌اید. سعی کنید به یاد بیاورید، بعد کلیک کنید و ببینید.

1 Run one commandاجرای یک دستور Doneانجام شد

Ask a tiny Alpine Linux container which Linux it is:

از یک کانتینر کوچک Alpine Linux بپرسید چه لینوکسی است:

bash
docker run --rm alpine cat /etc/os-release
output
NAME="Alpine Linux"
ID=alpine
VERSION_ID=3.24.2
PRETTY_NAME="Alpine Linux v3.24"
...

Everything after the image name is the command to run. Docker created a new container from alpine, ran cat /etc/os-release in it, printed the result, and the container stopped. --rm (Lesson 2) deleted it right away.

هر چیزی بعد از نام ایمیج دستوری است که اجرا می‌شود. Docker از alpine یک کانتینر جدید ساخت، cat /etc/os-release را در آن اجرا کرد، نتیجه را چاپ کرد و کانتینر متوقف شد. --rm (درس ۲) بلافاصله آن را حذف کرد.

docker run --rm alpine cat /etc/os-releaseoptions · image · your commandگزینه‌ها · ایمیج · دستور شما

Try another one:

یکی دیگر امتحان کنید:

bash
docker run --rm alpine echo "Hello from a new container"
output
Hello from a new container

2 Why --rm?چرا --rm؟ Doneانجام شد

Run a command without --rm, and name the container once:

یک دستور را بدون --rm اجرا کنید و نام کانتینر را once بگذارید:

bash
docker run --name once alpine echo hi

The command finished, but list all containers:

دستور تمام شد، ولی همه‌ی کانتینرها را فهرست کنید:

bash
docker ps -a
output
NAMES     STATUS                     # other columns left out
once      Exited (0) 1 second ago

A leftover. Every one-off command would leave one behind. Delete it:

یک باقی‌مانده. هر دستور یک‌باره یکی از این‌ها جا می‌گذارد. حذفش کنید:

bash
docker rm once

🔑 For one-off commands, always add --rm.

🔑 برای دستورهای یک‌باره همیشه --rm را اضافه کنید.

3 A shell in a new containerیک شل در کانتینر جدید Doneانجام شد

Want to look around Ubuntu without installing it? Run bash in a new ubuntu container, with -it so you can type (like exec -it in Lesson 6):

می‌خواهید بدون نصب، Ubuntu را بگردید؟ bash را در یک کانتینر جدید ubuntu اجرا کنید، با -it تا بتوانید تایپ کنید (مثل exec -it در درس ۶):

bash
docker run -it --rm ubuntu bash
output
root@e51c490f4f10:/#

You're inside a fresh Ubuntu. Check it:

داخل یک Ubuntu تازه هستید. بررسی کنید:

bash · inside
cat /etc/os-release
output
PRETTY_NAME="Ubuntu 26.04.1 LTS"
NAME="Ubuntu"
...

Leave the shell:

از شل خارج شوید:

bash · inside
exit

The shell was the container's program, so leaving it stopped the container, and --rm deleted it. Check: docker ps -a has no Ubuntu container.

شل همان برنامه‌ی کانتینر بود، پس خروج از آن کانتینر را متوقف کرد و --rm حذفش کرد. بررسی کنید: docker ps -a هیچ کانتینر Ubuntu ندارد.

❓ What if I forget -it?❓ اگر -it را فراموش کنم چه می‌شود؟

docker run --rm ubuntu bash returns immediately, with no prompt and no error. bash had no keyboard to read from, so it had nothing to do and exited. Interactive programs need -it.

docker run --rm ubuntu bash بلافاصله برمی‌گردد، بدون prompt و بدون خطا. bash صفحه‌کلیدی برای خواندن نداشت، پس کاری برای انجام نداشت و تمام شد. برنامه‌های تعاملی -it لازم دارند.

4 run -it or exec -it?run -it یا exec -it؟ Doneانجام شد

Both give you a shell, but in very different containers:

هر دو یک شل به شما می‌دهند، ولی در کانتینرهای خیلی متفاوت:

docker exec -it NAME bash docker run -it --rm IMAGE bash
Containerکانتینرan existing, running one (Lesson 6)یک کانتینر موجود و در حال اجرا (درس ۶)a brand-new one, from an imageیک کانتینر کاملاً جدید، از روی ایمیج
After exitبعد از exitthe container keeps runningکانتینر روشن می‌ماندthe container stops (and --rm deletes it)کانتینر متوقف می‌شود (و --rm حذفش می‌کند)
Use it toکاربردlook inside / fix a running appنگاه کردن داخل / رفع مشکل برنامه‌ی در حال اجراtry an image, run a quick toolامتحان یک ایمیج، اجرای سریع یک ابزار

You can delete the images you pulled if you like (Lesson 1): docker image rm alpine ubuntu.

اگر خواستید، ایمیج‌هایی را که دانلود کردید حذف کنید (درس ۱): docker image rm alpine ubuntu.
