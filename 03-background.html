Run in the backgroundاجرا در پس‌زمینه

hello-world printed a message and exited right away. Most real containers, like web servers, keep running. First you'll see what that does to your terminal, then fix it with -d.hello-world یک پیام چاپ کرد و بلافاصله تمام شد. بیشتر کانتینرهای واقعی، مثل وب‌سرورها، روشن می‌مانند. اول می‌بینید این کار با ترمینال شما چه می‌کند، بعد با -d حلش می‌کنید.

Press → or Space to startبرای شروع → یا Space را بزنید

First, meet nginxاول، آشنایی با nginx

What is nginx?nginx چیست؟

nginx is a web server: a program that runs a loop that never ends. It waits for a request, finds the page, and sends it back.nginx یک وب‌سرور است: برنامه‌ای که یک حلقه‌ی بی‌پایان را اجرا می‌کند. منتظر درخواست می‌ماند، صفحه را پیدا می‌کند و آن را برمی‌گرداند.

# nginx, in plain words
while True:
    request = wait_for_request()    # 1    page = find_page(request)       # 2    send_back(page, request.sender) # 3

Press → to follow one visit, step by step.→ را بزنید تا یک بازدید را قدم‌به‌قدم دنبال کنیم.

1 · LISTENگوش دادن

nginx waits. A browser sends a request: “give me /index.html”.nginx منتظر است. یک مرورگر درخواست می‌فرستد: «/index.html را بده».

2 · FINDپیدا کردن

nginx looks in its folder of pages and finds index.html.nginx در پوشه‌ی صفحه‌هایش می‌گردد و index.html را پیدا می‌کند.

3 · SEND BACKبرگرداندن

nginx sends the page back to the browser that asked. The page appears.nginx صفحه را به همان مرورگری که درخواست داده بود برمی‌گرداند. صفحه نمایش داده می‌شود.

🔁 AND AGAIN, FOREVERو دوباره، برای همیشه

Then it goes back to waiting. Unlike hello-world (Lesson 2), nginx never finishes by itself: it runs until you stop it.بعد دوباره منتظر می‌ماند. برخلاف hello-world (درس ۲)، nginx خودش تمام نمی‌شود: تا وقتی شما متوقفش نکنید اجرا می‌ماند.

Step 1قدم ۱

Run nginx in the foregroundاجرای nginx در پیش‌زمینه

Now let's run nginx in a container. As in Lesson 2, we name the container with --name; this time it's web.حالا nginx را در یک کانتینر اجرا می‌کنیم. مثل درس ۲ با --name به کانتینر نام می‌دهیم؛ این بار web.

bash
docker run --name web nginx

🔒 NO PROMPTبدون prompt

Your terminal is attached to the container: it shows nginx's log, and nginx will run until you stop it. You can't type other commands here.ترمینال شما به کانتینر چسبیده است: لاگ nginx را نشان می‌دهد و nginx تا وقتی متوقفش نکنید اجرا می‌ماند. اینجا نمی‌توانید دستور دیگری تایپ کنید.

⬇ NO PULL NEEDEDبدون pull

docker run downloaded the image by itself, because it wasn't on your PC. You don't always need docker pull first.docker run خودش ایمیج را هم دانلود کرد، چون روی کامپیوتر شما نبود. همیشه لازم نیست اول docker pull بزنید.

Step 2قدم ۲

Check it from a second terminalبررسی از یک ترمینال دوم

Leave the first terminal as it is. Open a new terminal window or tab (Ctrl+Shift+T in most Linux terminals) and run:ترمینال اول را همان‌طور رها کنید. یک پنجره یا تب جدید ترمینال باز کنید (در بیشتر ترمینال‌های لینوکس Ctrl+Shift+T) و اجرا کنید:

terminal 2 · newترمینال ۲ · جدید

STATUS · Up

This time docker ps without -a is enough, because the container is running. STATUS says Up.این بار docker ps بدون -a کافی است، چون کانتینر در حال اجراست. STATUS برابر Up است.

PORTS · 80/tcp

nginx listens on port 80 inside the container. Opening it in your browser comes in a later lesson.nginx روی پورت 80 داخل کانتینر گوش می‌دهد. باز کردن آن در مرورگر در درس‌های بعد.

Step 3قدم ۳

Stop it with Ctrl+Cتوقف با Ctrl+C

The first terminal is still stuck. Go to that terminal and press Ctrl+C:ترمینال اول هنوز گیر کرده است. به همان ترمینال بروید و Ctrl+C را بزنید:

terminal 1ترمینال ۱

docker ps
CONTAINER ID   IMAGE     COMMAND   CREATED   STATUS    PORTS     NAMES
ONLY THE HEADER LINEفقط خط عنوان

web is gone from the list. docker ps shows only running containers, and web isn't running anymore. (Other running containers would still be listed.)web از فهرست رفته است. docker ps فقط کانتینرهای در حال اجرا را نشان می‌دهد، و web دیگر اجرا نمی‌شود. (کانتینرهای دیگرِ در حال اجرا هنوز در فهرست هستند.)

Step 3 · Stopped, not deletedقدم ۳ · متوقف، نه حذف‌شده

It's only stoppedفقط متوقف شده

It wasn't deleted, only stopped. Use the switch that shows all containers, including stopped ones (you learned it in Lesson 2):حذف نشده، فقط متوقف شده. از سوئیچی استفاده کنید که همه‌ی کانتینرها، حتی متوقف‌شده‌ها، را نشان می‌دهد (آن را در درس ۲ یاد گرفتید):

bash
docker ps -a
CONTAINER ID   IMAGE     COMMAND                  CREATED         STATUS                    PORTS     NAMES
17dcab6b72b6   nginx     "/docker-entrypoint.…"   5 seconds ago   Exited (0) 1 second ago             web
docker rm web
web
Exited (0)

There it is: stopped (Exited), but still there. docker ps hides it; docker ps -a shows it.اینجاست: متوقف شده (Exited)، ولی هنوز وجود دارد. docker ps نشانش نمی‌دهد؛ docker ps -a نشان می‌دهد.

Step 5 · Delete itقدم ۵ · حذفش کنید

Delete it, keep the imageحذف کانتینر، نگه داشتن ایمیج

bash
docker rm web
web
docker ps -a
CONTAINER ID   IMAGE     COMMAND   CREATED   STATUS    PORTS     NAMES
# ✅ web is gone for good, even from -a
docker image ls nginx
IMAGE          ID             DISK USAGE   CONTENT SIZE   EXTRA
nginx:latest   f9ea18bfa4fa        243MB         66.7MB
⚠ RUNNING?در حال اجرا؟

You can't docker rm a running container. Stop it first, or use docker rm -f web (force), which stops and deletes in one go.کانتینر در حال اجرا را نمی‌توانید با docker rm حذف کنید. اول متوقفش کنید، یا از docker rm -f web (اجباری) استفاده کنید که در یک قدم متوقف و حذف می‌کند.

🔑 The image is still there. Keep it: we need it in the next lessons.🔑 ایمیج هنوز سر جایش است. نگهش دارید، چون در درس‌های بعد به آن نیاز داریم.
