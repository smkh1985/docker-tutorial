Lesson 3 — Run in the background درس ۳ — اجرای کانتینر در پس‌زمینه

hello-world printed a message and exited right away. Most real containers, like web servers, keep running. First you'll see what that does to your terminal, then fix it with -d.

hello-world یک پیام چاپ کرد و بلافاصله تمام شد. بیشتر کانتینرهای واقعی، مثل وب‌سرورها، روشن می‌مانند. اول می‌بینید این کار با ترمینال شما چه می‌کند، بعد با -d حلش می‌کنید.

🧠 Blurred commands are ones you've already learned. Try to remember them, then click to check.

🧠 دستورهای محو را قبلاً یاد گرفته‌اید. سعی کنید به یاد بیاورید، بعد کلیک کنید و ببینید.

1 Run nginx in the foregroundاجرای nginx در پیش‌زمینه Doneانجام شد

nginx is a popular web server. Once started, it runs until you stop it. As in Lesson 2, we name the container with --name; this time it's web.

nginx یک وب‌سرور محبوب است. وقتی روشن شود، تا وقتی متوقفش نکنید اجرا می‌ماند. مثل درس ۲ با --name به کانتینر نام می‌دهیم؛ این بار web.

bash
docker run --name web nginx
output
Unable to find image 'nginx:latest' locally     # first time only: download
latest: Pulling from library/nginx
...
Status: Downloaded newer image for nginx:latest
/docker-entrypoint.sh: Configuration complete; ready for start up
2026/10/10 09:10:49 [notice] 1#1: nginx/1.31.6
2026/10/10 09:10:49 [notice] 1#1: start worker processes
...
█   ← no prompt. The terminal is stuck here.

You don't get your prompt back. Your terminal is attached to the container: it shows nginx's log, and nginx will run until you stop it. You can't type other commands here.

prompt به شما برنمی‌گردد. ترمینال شما به کانتینر چسبیده است: لاگ nginx را نشان می‌دهد و nginx تا وقتی متوقفش نکنید اجرا می‌ماند. اینجا نمی‌توانید دستور دیگری تایپ کنید.

docker run also downloaded the image by itself, because it wasn't on your PC. You don't always need docker pull first.

docker run خودش ایمیج را هم دانلود کرد، چون روی کامپیوتر شما نبود. همیشه لازم نیست اول docker pull بزنید.

2 Check it from a second terminalبررسی از یک ترمینال دوم Doneانجام شد

Leave the first terminal as it is. Open a new terminal window or tab (Ctrl+Shift+T in most Linux terminals) and run:

ترمینال اول را همان‌طور رها کنید. یک پنجره یا تب جدید ترمینال باز کنید (در بیشتر ترمینال‌های لینوکس Ctrl+Shift+T) و اجرا کنید:

bash
docker ps
output
CONTAINER ID   IMAGE     COMMAND                  CREATED         STATUS         PORTS     NAMES
17dcab6b72b6   nginx     "/docker-entrypoint.…"   3 seconds ago   Up 2 seconds   80/tcp    web

This time docker ps without -a is enough, because the container is running. STATUS says Up. PORTS 80/tcp means nginx listens on port 80 inside the container; opening it in your browser comes in a later lesson.

این بار docker ps بدون -a کافی است، چون کانتینر در حال اجراست. STATUS برابر Up است. PORTS 80/tcp یعنی nginx روی پورت 80 داخل کانتینر گوش می‌دهد؛ باز کردن آن در مرورگر در درس‌های بعد.

Checklistچک‌لیست

3 Stop it with Ctrl+Cتوقف با Ctrl+C Doneانجام شد

The first terminal is still stuck. To stop the container and get your terminal back, go to that terminal and press Ctrl+C:

ترمینال اول هنوز گیر کرده است. برای متوقف کردن کانتینر و برگشتن به ترمینال، به همان ترمینال بروید و Ctrl+C را بزنید:

output
^C
2026/10/10 09:10:50 [notice] 1#1: signal 2 (SIGINT) received, exiting
...
2026/10/10 09:10:50 [notice] 1#1: exit
$   ← your prompt is back

nginx shut down. Run the same check as in step 2:

nginx خاموش شد. همان بررسی قدم ۲ را دوباره انجام دهید:

bash
docker ps
output
CONTAINER ID   IMAGE     COMMAND   CREATED   STATUS    PORTS     NAMES

Only the header line: web is gone from the list. docker ps shows only running containers, and web isn't running anymore. (If you have other running containers, they'll still be listed, but not web.)

فقط خط عنوان: web از فهرست رفته است. docker ps فقط کانتینرهای در حال اجرا را نشان می‌دهد، و web دیگر اجرا نمی‌شود. (اگر کانتینرهای دیگری در حال اجرا دارید، آن‌ها هنوز در فهرست هستند، ولی web نیست.)

But it wasn't deleted, only stopped. Want to see it? Use the switch that shows all containers, including stopped ones (you learned it in Lesson 2):

ولی حذف نشده، فقط متوقف شده. می‌خواهید ببینیدش؟ از سوئیچی استفاده کنید که همه‌ی کانتینرها، حتی متوقف‌شده‌ها، را نشان می‌دهد (آن را در درس ۲ یاد گرفتید):

bash
docker ps -a
output
CONTAINER ID   IMAGE     COMMAND                  CREATED         STATUS                    PORTS     NAMES
17dcab6b72b6   nginx     "/docker-entrypoint.…"   5 seconds ago   Exited (0) 1 second ago             web

Delete it, so the name web is free for the next step:

حذفش کنید تا نام web برای قدم بعد آزاد شود:

bash
docker rm web
Checklistچک‌لیست

4 Now run it in the background with -dحالا اجرا در پس‌زمینه با -d Doneانجام شد

Same command, plus -d (detached):

همان دستور، به‌اضافه‌ی -d (detached، یعنی جدا شده):

bash
docker run -d --name web nginx
output
1c76533ac4cbf87fdbd0e208968f0b8bb201b670a2777d22770de41178d25b03   # the new container's full ID
$   ← prompt back right away

Docker prints the container's ID and gives you your terminal back. nginx keeps running in the background:

Docker شناسه‌ی کانتینر را چاپ می‌کند و ترمینال را به شما برمی‌گرداند. nginx در پس‌زمینه اجرا می‌ماند:

bash
docker ps
output
CONTAINER ID   IMAGE     COMMAND                  CREATED         STATUS         PORTS     NAMES
1c76533ac4cb   nginx     "/docker-entrypoint.…"   9 seconds ago   Up 3 seconds   80/tcp    web
Without -d (foreground)بدون -d (پیش‌زمینه) With -d (background)با -d (پس‌زمینه)
TerminalترمینالBusy, shows the logمشغول، لاگ را نشان می‌دهدFree right awayبلافاصله آزاد
How to stopروش توقفCtrl+Cdocker stop web

5 Stop and delete itتوقف و حذف Doneانجام شد

5.1 · Stop it۵.۱ · متوقفش کنید

This time the terminal is not stuck, so there is nothing to press Ctrl+C on. Stop the container with a command instead (you saw it in the table above):

این بار ترمینال گیر نکرده است، پس Ctrl+C اینجا کاری نمی‌کند. کانتینر را با یک دستور متوقف کنید (آن را در جدول بالا دیدید):

bash
docker stop web
output
web

5.2 · Is it still running?۵.۲ · هنوز در حال اجراست؟

List the running containers:

کانتینرهای در حال اجرا را فهرست کنید:

bash
docker ps
output
CONTAINER ID   IMAGE     COMMAND   CREATED   STATUS    PORTS     NAMES

No web: it's not running.

web نیست: در حال اجرا نیست.

5.3 · Does it still exist?۵.۳ · هنوز وجود دارد؟

List all containers, including stopped ones:

همه‌ی کانتینرها را، حتی متوقف‌شده‌ها، فهرست کنید:

bash
docker ps -a
output
CONTAINER ID   IMAGE     COMMAND                  CREATED         STATUS                              PORTS     NAMES
1c76533ac4cb   nginx     "/docker-entrypoint.…"   9 seconds ago   Exited (0) Less than a second ago             web

There it is: stopped (Exited), but still there.

اینجاست: متوقف شده (Exited)، ولی هنوز وجود دارد.

5.4 · Delete it۵.۴ · حذفش کنید

bash
docker rm web
output
web

⚠ You can't docker rm a running container. Stop it first, or use docker rm -f web (force), which stops and deletes in one go.

⚠ کانتینر در حال اجرا را نمی‌توانید با docker rm حذف کنید. اول متوقفش کنید، یا از docker rm -f web (اجباری) استفاده کنید که در یک قدم متوقف و حذف می‌کند.

5.5 · Check it's gone۵.۵ · بررسی کنید حذف شده

Look at all containers again:

دوباره همه‌ی کانتینرها را ببینید:

bash
docker ps -a
output
CONTAINER ID   IMAGE     COMMAND   CREATED   STATUS    PORTS     NAMES

✅ web is gone for good, even from -a.

✅ web برای همیشه حذف شد، حتی در -a هم نیست.

5.6 · The image is still there۵.۶ · ایمیج هنوز هست

Remember: we only removed the container. The image is still there. Check it:

یادتان باشد: فقط کانتینر را حذف کردیم. ایمیج هنوز سر جایش است. بررسی کنید:

bash
docker image ls nginx
output
IMAGE          ID             DISK USAGE   CONTENT SIZE   EXTRA
nginx:latest   f9ea18bfa4fa        243MB         66.7MB

🔑 Keep this image. We need it in the next lessons.

🔑 این ایمیج را نگه دارید، چون در درس‌های بعد به آن نیاز داریم.
