Before we start · An exampleقبل از شروع · یک مثال

From a recipe to an imageاز دستور پخت تا ایمیج

Imagine you have a web application. To run, it needs an operating system (a Linux like Alpine or Ubuntu), Python, Django, Java, npm, libraries… You write a recipe: a text file that lists what you need, layer by layer.فرض کنید یک وب‌اپلیکیشن دارید. برای اجرا به یک سیستم‌عامل (یک لینوکس مثل Alpine یا Ubuntu)، Python، Django، Java، npm، کتابخانه‌ها و … نیاز دارد. یک دستور پخت می‌نویسید: یک فایل متنی که لایه‌به‌لایه می‌گوید چه چیزهایی لازم دارید.

📄 recipe.txt
1Install Linux (e.g. Ubuntu or Alpine)نصب لینوکس (مثلاً Ubuntu یا Alpine)
2Install Pythonنصب Python
3Install Python packages (Django, …)نصب بسته‌های Python (مثل Django و …)
4Install other tools (Java, npm libraries, …)نصب ابزارهای دیگر (Java، کتابخانه‌های npm و …)
5Copy your web app's codeکپی کردن کد وب‌اپلیکیشن شما
THE BOX = AN IMAGEجعبه = ایمیج

Docker follows the recipe, downloads and installs everything, and puts it all in one package (a box). That package is an image. It contains everything your app needs, but it's not running.Docker دستور پخت را دنبال می‌کند، همه چیز را دانلود و نصب می‌کند و همه را در یک بسته (یک جعبه) می‌گذارد. این بسته ایمیج است. همه‌ی چیزهایی که برنامه‌تان لازم دارد را دارد، ولی در حال اجرا نیست.

In Docker, this recipe file is called a Dockerfile. You'll write one in Lesson 17.در Docker به این فایل دستور پخت Dockerfile می‌گویند. در درس ۱۷ یکی می‌نویسید.

Step 1قدم ۱

Image vs containerایمیج و کانتینر

IMAGEایمیج

A package: a program plus everything it needs to run. It just sits on your disk.یک بسته: یک برنامه به‌همراه هر چیزی که برای اجرا لازم دارد. فقط روی دیسک شما ذخیره شده است.

CONTAINERکانتینر

A running copy made from an image. From one image you can start many containers.یک نسخه‌ی در حال اجرا که از روی ایمیج ساخته می‌شود. از یک ایمیج می‌توانید چندین کانتینر بسازید.

THIS LESSONاین درس

This lesson is only about images. Containers come next.این درس فقط درباره‌ی ایمیج‌هاست. کانتینرها در درس بعد.

Use a public imageاز یک ایمیج عمومی استفاده کنید

Download a ready-made image from a Docker registry, an online library of images. The default one is Docker Hub.یک ایمیج آماده را از یک رجیستری Docker دانلود کنید؛ یک کتابخانه‌ی آنلاین از ایمیج‌ها. رجیستری پیش‌فرض Docker Hub است.

Step 3قدم ۳

Pull an image from Docker Hubدانلود ایمیج از Docker Hub

Docker Hub is the public library of images. Pull means download. Let's pull Alpine, a tiny Linux of only a few MB, and then hello-world, a tiny test image.Docker Hub کتابخانه‌ی عمومی ایمیج‌هاست. Pull یعنی دانلود. بیایید Alpine را دانلود کنیم؛ یک لینوکس خیلی کوچک که فقط چند مگابایت است. بعد هم hello-world را؛ یک ایمیج آزمایشی خیلی کوچک.

bash
docker pull alpine
Using default tag: latest                  # no tag given → latest
latest: Pulling from library/alpine
e2de96513ba9: Pull complete                # an image is made of parts (layers)
Digest: sha256:294b683cb724975bec92...
Status: Downloaded newer image for alpine:latest
docker.io/library/alpine:latest            # the full name
docker pull hello-world
Using default tag: latest
latest: Pulling from library/hello-world
4f55086f7dd0: Pull complete
Digest: sha256:5e23090353324d887c48...
Status: Downloaded newer image for hello-world:latest
docker.io/library/hello-world:latest
Step 4قدم ۴

Check it's thereبررسی کنید دانلود شده

List your images again. This time you see both images:دوباره ایمیج‌ها را فهرست کنید. این بار هر دو ایمیج را می‌بینید:

bash
docker image ls
IMAGE                ID             DISK USAGE   CONTENT SIZE   EXTRA
alpine:latest        294b683cb724         13MB         3.94MB
hello-world:latest   5e2309035332       25.9kB         9.49kB
docker image ls alpine
IMAGE           ID             DISK USAGE   CONTENT SIZE   EXTRA
alpine:latest   294b683cb724         13MB         3.94MB
# add a name to show just that one image (handy when your list is long)
IMAGE

The name, written name:tag. The tag is usually a versionنام ایمیج، به شکل name:tag. تگ معمولاً نسخه است

ID

A unique ID. You can use it instead of the nameیک شناسه‌ی یکتا. می‌توانید به‌جای نام از آن استفاده کنید

DISK USAGE

Space it takes on your disk (unpacked). A whole Linux in 13 MB!فضایی که روی دیسک شما می‌گیرد (باز شده). یک لینوکس کامل در ۱۳ مگابایت!

CONTENT SIZE

Compressed size, roughly what gets downloadedحجم فشرده، تقریباً همان مقداری که دانلود می‌شود

EXTRA

U means a container is using this image. Empty for nowU یعنی یک کانتینر از این ایمیج استفاده می‌کند (use). فعلاً خالی است

Step 4 · Reading the nameقدم ۴ · خواندن نام

Every image has a name and a tagهر ایمیج یک نام و یک تگ دارد

alpinenameنام:latesttag · usually a versionتگ · معمولاً نسخه
❓ docker images

Online tutorials show docker images with REPOSITORY / TAG / SIZE columns. It's the older name of the same command. Docker 29 changed the default columns. Both show the same images.آموزش‌های اینترنتی docker images را با ستون‌های REPOSITORY / TAG / SIZE نشان می‌دهند. این نام قدیمی همین دستور است. Docker نسخه‌ی 29 ستون‌های پیش‌فرض را تغییر داد. هر دو همان ایمیج‌ها را نشان می‌دهند.

Step 4 · The full nameقدم ۴ · نام کامل

You typed alpineشما نوشتید alpine

docker.io/library/alpine:latest
docker.io

Docker Hub's addressآدرس Docker Hub

library

Where Docker Hub keeps official imagesجایی که Docker Hub ایمیج‌های رسمی را نگه می‌دارد

alpine

The image name you typedنام ایمیجی که نوشتید

latest

The tag. You gave none, so latestتگ. تگی ندادید، پس latest

You typed alpine, but Docker pulled alpine:latest. Without a tag, Docker always uses latest.شما alpine را نوشتید ولی Docker ایمیج alpine:latest را دانلود کرد. اگر تگ ندهید، Docker همیشه latest را برمی‌دارد.

Step 5قدم ۵

Delete itحذف ایمیج

bash
docker image rm alpine
Untagged: alpine:latest                    # the name is removed
Deleted: sha256:294b683cb724975bec92...    # the files are removed
docker image ls alpine
IMAGE   ID             DISK USAGE   CONTENT SIZE   EXTRA
SHORTERکوتاه‌تر

docker rmi alpine is a shorter way to write the same thing.docker rmi alpine شکل کوتاه‌تر همین دستور است.
