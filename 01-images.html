1 Image vs containerایمیج و کانتینر Doneانجام شد

An image is a read-only package: a program plus everything it needs to run. It just sits on your disk.

ایمیج یک بسته‌ی فقط‌خواندنی است: یک برنامه به‌همراه هر چیزی که برای اجرا لازم دارد. فقط روی دیسک شما ذخیره شده است.

A container is a running copy made from an image. From one image you can start many containers, like baking many cakes from one recipe.

کانتینر یک نسخه‌ی در حال اجراست که از روی ایمیج ساخته می‌شود. از یک ایمیج می‌توانید چندین کانتینر بسازید، مثل پختن چند کیک از روی یک دستور پخت.

Imageایمیجthe recipe · on disk · read-onlyدستور پخت · روی دیسک · فقط‌خواندنی
docker run (next lesson)(درس بعد)
Container 1کانتینر ۱
Container 2کانتینر ۲
Container 3کانتینر ۳

This lesson is only about images. Containers come next.

این درس فقط درباره‌ی ایمیج‌هاست. کانتینرها در درس بعد.

2 List your imagesفهرست ایمیج‌ها Doneانجام شد

Show every image on your PC:

همه‌ی ایمیج‌های روی کامپیوترتان را نشان دهید:

bash
docker image ls

If your list is long, show just one image by adding its name. Let's find hello-world, which was downloaded when you tested Docker in Lesson 0:

اگر فهرست شما طولانی است، با اضافه کردن نام فقط یک ایمیج را نشان دهید. بیایید hello-world را پیدا کنیم که موقع تست Docker در درس ۰ دانلود شد:

bash
docker image ls hello-world
output
IMAGE                ID             DISK USAGE   CONTENT SIZE   EXTRA
hello-world:latest   5e2309035332       25.9kB         9.49kB
Columnستون Meaningمعنی
IMAGEThe name, written name:tag. The tag is usually a version; latest is the defaultنام ایمیج، به شکل name:tag. تگ معمولاً نسخه است؛ latest پیش‌فرض است
IDA unique ID. You can use it instead of the nameیک شناسه‌ی یکتا. می‌توانید به‌جای نام از آن استفاده کنید
DISK USAGESpace it takes on your disk (unpacked)فضایی که روی دیسک شما می‌گیرد (باز شده)
CONTENT SIZECompressed size, roughly what gets downloadedحجم فشرده، تقریباً همان مقداری که دانلود می‌شود
EXTRAU means a container is using this imageU یعنی یک کانتینر از این ایمیج استفاده می‌کند (use)

Don't see hello-world? Run docker pull hello-world (you'll learn this command in the next step) and try again.

hello-world را نمی‌بینید؟ docker pull hello-world را اجرا کنید (این دستور را در قدم بعد یاد می‌گیرید) و دوباره امتحان کنید.

❓ Online tutorials show docker images with REPOSITORY / TAG / SIZE columns. Why is mine different?❓ آموزش‌های اینترنتی docker images را با ستون‌های REPOSITORY / TAG / SIZE نشان می‌دهند. چرا مال من فرق دارد؟

docker images is the older name of the same command. Docker 29 changed the default columns. Both show the same images.

docker images نام قدیمی همین دستور است. Docker نسخه‌ی 29 ستون‌های پیش‌فرض را تغییر داد. هر دو همان ایمیج‌ها را نشان می‌دهند.

3 Pull an image from Docker Hubدانلود ایمیج از Docker Hub Doneانجام شد

Docker Hub is the public library of images. Pull means download. Let's pull Alpine, a tiny Linux of only a few MB:

Docker Hub کتابخانه‌ی عمومی ایمیج‌هاست. Pull یعنی دانلود. بیایید Alpine را دانلود کنیم؛ یک لینوکس خیلی کوچک که فقط چند مگابایت است:

bash
docker pull alpine
output
Using default tag: latest                  # no tag given → latest
latest: Pulling from library/alpine
e2de96513ba9: Pull complete                # an image is made of parts (layers)
Digest: sha256:294b683cb724975bec92...
Status: Downloaded newer image for alpine:latest
docker.io/library/alpine:latest            # the full name

You typed alpine, but Docker pulled alpine:latest. Without a tag, Docker always uses latest.

شما alpine را نوشتید ولی Docker ایمیج alpine:latest را دانلود کرد. اگر تگ ندهید، Docker همیشه latest را برمی‌دارد.

Checklistچک‌لیست

4 Check it's thereبررسی کنید دانلود شده Doneانجام شد

bash
docker image ls alpine
output
IMAGE           ID             DISK USAGE   CONTENT SIZE   EXTRA
alpine:latest   294b683cb724         13MB         3.94MB

A whole Linux system in 13 MB. Run docker image ls without a name too: both hello-world and alpine are in the list.

یک سیستم لینوکس کامل در ۱۳ مگابایت. docker image ls را بدون نام هم اجرا کنید: هر دو ایمیج hello-world و alpine در فهرست هستند.

5 Delete itحذف ایمیج Doneانجام شد

bash
docker image rm alpine
output
Untagged: alpine:latest                    # the name is removed
Deleted: sha256:294b683cb724975bec92...    # the files are removed

Check it's gone. Only the header line is left:

بررسی کنید که حذف شده. فقط خط عنوان ستون‌ها باقی می‌ماند:

bash
docker image ls alpine
output
IMAGE   ID             DISK USAGE   CONTENT SIZE   EXTRA

docker rmi alpine is a shorter way to write the same thing.

docker rmi alpine شکل کوتاه‌تر همین دستور است.

🔑 Keep hello-world. In the next lesson you'll run it as a container.

🔑 hello-world را نگه دارید. در درس بعد آن را به‌صورت کانتینر اجرا می‌کنید.
